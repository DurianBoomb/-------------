### 3.2 数据库 · MongoDB 文档型 NoSQL

**访问方式：**
- **云对象内**：`uniCloud.database()` 获取 db 实例，链式调用 `.collection().where().get()/.add()/.update()/.remove()`
- **前端直连**：`uniCloud.database()` + JQL（支持 clientDB 权限校验）
- **Schema 权限表达式**：每张表定义 create/read/update/delete 的权限规则（如 `"auth.uid != null"`）

> 注意：当前项目全部走云对象调用，还未启用前端 JQL clientDB 直连。

## 四、核心数据链路

### 4.1 Coze 级数据结构（survey 云对象消费）

问卷主体采用 **Coze 友好版数据结构**，AI 只需写自然语言文本，不涉及数学运算：

```javascript
{
  tag: '确诊为烤肠',              // 标签名
  title: '你被确诊为什么东西？',    // 页面标题
  dims: ['淀粉含量', '加肉程度', '受欢迎度', '性价比'],  // 3-7个维度名
  qs: [
    { title: '周末你更倾向于一个人待着？', dim: '淀粉含量' },
    // ... 每个维度 × 3 题
  ],
  resultTypes: [
    {
      name: '纯正淀粉肠',
      emoji: '🌭',
      emojiBg: '#FFE4B5',
      desc: '...',
      match: '淀粉含量'     // 匹配维度名
    }
    // ... 数量 = dims.length
  ]
}
```

**校验规则（云函数 `validateQuestionnaire`）：**
- `dims` 长度 3-7
- `qs` 数量 = dims数量 × 3（±1 容差）
- 每题 `dim` 必须在 `dims` 中
- `resultTypes` ≥ 1
- 每个 `match` 必须在 `dims` 中
- `tag` 必须与输入标签名一致

### 4.2 评分逻辑

```
每题选项固定 3 个：反对(1分) / 中立(2分) / 同意(3分)

维度得分 = 该维度所有题目得分之和
归一化：((raw - minPossible) / (maxPossible - minPossible)) × 100

结果匹配（survey 云对象 + tools 云对象共用两套算法）：
  A) 旧版（tools）：范围匹配 → ranges[{dimensionIndex, min, max}]
  B) 新版（survey）：最近邻匹配 → prototypes 向量欧氏距离
  C) Coze 友好版（前端）：最高得分维度名 match 到 resultType

客户端评分（答题页 answer-quiz）：
  1. 每题记录 { dim, score }
  2. 各维度平均分归一化 0-100
  3. 最高分维度匹配 resultTypes[].match
  4. 加 ±5 噪声美化雷达图显示
```

### 4.3 Coze AI 问卷生成流

```
用户点击"生成"（前有激励视频广告）
  → 前端调用 survey.generateFromCoze({ tagName, tagDesc })
  → 云函数请求 Coze 工作流 API（HTTP POST）
     URL: https://wtgfb24qdy.coze.site/run
     Auth: Bearer token
     Body: { tag_name, tag_desc }
     Timeout: 60s
  → Coze 返回 { questionnaire: { dims, qs, resultTypes, ... } }
  → 校验结构 → 存入 surveys 集合 → 返回 surveyId
```

## 五、前端业务逻辑

### 5.1 首页（index）
- 2 列工具卡片网格，`slideUpElastic` 入场动画
- `onShow` 重建 DOM 确保每次重播动画
- 果冻按压反馈（hover-class + transition 分离）

### 5.2 标签池（quiz-home）
- 大号标签（推荐）+ 小号标签（全部），弹性掉落动画
- "换一批" 按钮随机刷新
- 搜索页入口

### 5.3 答题页（answer-quiz）
- **一题一屏**，选中选项即过
- 三个固定选项：反对 / 中立 / 同意
- 入场 `slideUpElastic`（0.45s）+ 离场 `fadeOutUp`（0.2s）
- 选中态保持 400ms 后切题
- 防抖锁防止快速点击跳题
- 选项 DOM 分离：外层 hover-class（按压），内层 animation（入场+选中样式）

### 5.4 结果页（result）
- 头像 + 标题 + 徽章 + 描述卡片 + 雷达图
- Canvas 2D 动态绘制，`easeOutBack` 弹性入场动画
- 再来一次 + 分享按钮

### 5.5 用户画像（profile）
- 汇总用户所有答题结果（去重标签）
- 显示每项的结果类型和 emoji

### 5.6 搜索页
- 搜索框 + 固定高度搜索结果区
- 手风琴分类（内嵌标签池），展开/收起动画

## 六、已知的坑和小程序限制

| 问题 | 解决方案 |
|------|----------|
| scroll-view padding 不生效 | 内套 body-inner 容器 |
| animation 和 hover-class transform 冲突 | DOM 分层：外层按压，内层动画 |
| 小程序 `:key` 表达式不支持 | 用 `:key="'prefix-' + idx"` 字符串拼接 |
| `?.` 可选链在 WXML 不支持 | 用 `curQ.title` 而非 `curQ?.title` |
| HBuilderX 模拟器热更新缓存 | 停止运行 → 删 `unpackage` 缓存 → 重新运行 |
| 小程序 rpx 基准 | `rpxCalcMaxDeviceWidth: 375`，以 375 设计稿为准 |
| 分包优化 | `optimization.subPackages: true`（manifest.json） |
| Token 过期 | `resToLogin: true` 自动拦截跳登录页 |
