# 群友成分鉴定——问卷设计

## 元数据

| 字段 | 值 |
|------|-----|
| 版本 | 1.0 |
| 标签 | 群友成分鉴定 |
| 标签描述 | 每个群都有二十八种人——你占哪一种。也可能你一个人占了二十八种。 |
| 问卷标题 | 你在群里是个什么成分？ |
| 维度数 | 7 |
| 题目数 | 21（7维×3题） |
| 结果类型数 | 28 |
| 评分方式 | 向量匹配（欧几里得距离） |

---

## 七维度定义

| 维度 | 含义 | 低分画面 | 高分画面 |
|------|------|------|------|
| 冒泡率 | 发言频率、存在感 | 加了群跟没加一样 | 每条消息下面都有他 |
| 刺人度 | 抬杠、怼人、阴阳怪气 | 和气生财型 | 见谁说谁 |
| 抽象值 | 内容离谱荒诞程度 | 发的全是正经资讯 | 发的正常人看不懂 |
| 挑头欲 | 带话题、造梗、组织 | 跟随型，从不发起 | 群没他就冷场 |
| 显摆瘾 | 凡尔赛、自我展示 | 没人知道他长什么样 | 三句话不离自己 |
| 持久度 | 在线时长、粘性 | 偶尔冒泡就走 | 凌晨四点还在 |
| 群妈心 | 归属感、维护欲 | 群炸了跟他没关系 | 比群主管得还宽 |
