### 3. 跨平台 Canvas 2D 适配（排查 3 轮）

#### 问题 1：`canvas.requestAnimationFrame is not a function`

- **表现**：模拟器中直接报 TypeError，动画崩溃
- **根因**：部分环境下（模拟器/H5）Canvas 2D 节点上没有 `requestAnimationFrame` 方法
- **修复**：添加 rAF 降级包装 `_raf`/`_caf`，canvas 支持直接用，不支持降级到 `setTimeout(fn, 17)`
- **涉及文件**：`result.vue` + `radar-test.vue` 同步修复

#### 问题 2：H5 模式下 `uni.createSelectorQuery().in(this).fields({ node: true })` 拿不到 canvas 节点

- **表现**：页面白屏，无任何报错（`initRadar` 静默 return）
- **根因**：`fields({ node: true })` 是**微信小程序专属 API**，H5 下返回空
- **修复**：`initRadar` 改为双通道策略
  - **H5**: `document.getElementById('radarCanvas')` 直取 DOM
  - **小程序**: 原 `uni.createSelectorQuery` 方式不动
- **涉及文件**：`result.vue` + `radar-test.vue`

## 二、技术要点记录

### Canvas 2D 跨平台注意事项

| 平台 | Canvas 获取方式 | rAF 来源 |
|------|----------------|---------|
| 微信小程序 | `uni.createSelectorQuery().in(this).fields({ node: true })` | `canvas.requestAnimationFrame` |
| H5 (Web) | `document.getElementById('id')` | `window.requestAnimationFrame` 或 `setTimeout` 降级 |

**关键经验**：`fields({ node: true })` 不是 Web 标准 API，只在微信小程序运行时有效。H5 下必须直接用 DOM API 取 canvas 元素。

### 时间窗机制（`frac` / `win`）

`win(i, N, startBase, startSpan, dur)` 是 N 维自适应 stagger 的核心：

- `frac(i, N)` = `i / (N-1)`，将维度索引归一化到 [0, 1]
- 每个维度的动画起始时间 = `startBase + frac(i, N) * startSpan`
- 结束时间 = 起始时间 + `dur`

这样无论 N=3 还是 N=10，各维度的动画窗口都会均匀分布在时间轴上，不需要手动为每个维度写硬编码 delay。

### Canvas 全局状态泄漏

`textAlign`、`textBaseline`、`globalAlpha`、`lineCap`、`lineJoin`、`setLineDash` 在 Canvas 中是**全局状态**。每层动画绘制前必须显式重置，否则会影响后续图层。

10 层全量重绘中，`drawFrame` 开头做了统一重置：
```js
ctx.globalAlpha = 1
ctx.setLineDash([])
ctx.lineCap = 'butt'
ctx.lineJoin = 'miter'
ctx.textAlign = 'start'
ctx.textBaseline = 'alphabetic'
```

每层内部修改全局状态后也在末尾恢复了。这是从之前分享图 `textAlign` 泄漏的教训中沉淀下来的习惯。

## 三、经验总结

### 1. Figma 参数驱动开发效率极高

这次和上次分享图的经验一致：有精确参数（坐标/颜色/字号/时间窗全部标死），Canvas 移植一次到位。之前手估反复调 5-6 轮还对不上，Figma 参数到位后一轮通过。

### 2. 逐层实现 + 逐层验证的心智模型

10 层动画没有一次写完就跑，而是分了 10 个独立函数 + 1 个编排函数。每层可以单独 `return` 测试，也可以在 `drawFrame` 中注释掉某层观察整体效果。这种"乐高式"结构后续调时序/改参数非常方便。

### 3. 跨平台适配的问题隐藏在运行时静默失败中

Canvas 2D 在 H5 和小程序的 API 差异导致了两次静默失败：
- 第一次：`canvas.requestAnimationFrame` 不存在 → 报错被看到
- 第二次：`createSelectorQuery` 拿不到节点 → 静默 return，完全看不到
- **教训**：跨平台 Canvas 代码需要显式区分平台路径，不能依赖 "silent fallback"

### 4. 复盘文档最好是日更的

今天的工作横跨了 CSS 动画 + Canvas 绘制 + 跨平台调试三条线，如果不写复盘，下次先生开工时很难快速捡起来。复盘文档就是给未来的自己看的"工作连续性的保险"。

### 5. 先生有 ADHD，注意力容易被无限细节吸引

今天在 Canvas 的 `globalAlpha` 泄漏、`textAlign` 分支这些细节上反复调了很久，虽然必要，但时间管理上应该设置一个"够了，再调收益递减"的信号。下次可以在开始工作前先约定每个图层的调校上限时间。
