# 频繁闪现「加载中」问题

## 现象

用户在使用过程中，哪怕不到半秒的操作也会出现加载中状态（骨架屏/loading 提示），频繁闪动影响观感。

## 问题定位

### 元凶1：`pin-topbar.vue` 的 `refresh()` — 每次回首页都闪骨架屏

`refresh()` 一调用就立刻设 `loading = true`，显示 5 张灰色脉冲骨架卡。

`refresh()` 被调用的时机：
- `onReady`（首页首次渲染完成）
- `onShow`（从任何页面返回首页）
- 广告置顶完成后

`ps.draw()` 云函数调用通常很快（几百毫秒），结果就是：骨架屏闪一下（200-500ms）→ 正文出现。用户只要在页面之间来回切换，次次都要闪。

**根因：没有区分「首次加载」（无数据）和「刷新已有数据」（有旧数据），一律显示 loading。**

### 元凶2：`index.vue` 的 `showGrid` 切换 — 可能空白闪烁

```javascript
onShow() {
    // ...
    this.showGrid = false
    this.$nextTick(() => {
        this.showGrid = true
    })
}
```

`showGrid = false` → `$nextTick` → `showGrid = true`，虽然中间间隔极短，但在低端机型上可能出现空白闪烁。

### 非问题项（保留现状）

- `pin-terminal-entry.vue` 的广告播放 loading：广告确实需要等待，loading 合理
- `ad-utils.js` 的广告处理 loading：同上，不做改动

## 修复方案

### 改 `pin-topbar.vue` 的 `refresh()` — 加延迟阈值

核心思路：**已有旧数据时，不立刻显示 loading，加 300ms 延迟阈值。请求在阈值内返回就静默更新，超过阈值才显示骨架屏。**

```javascript
async refresh() {
    if (!this.currentUid) {
        this.loading = false
        this.cards = []
        return
    }
    // 已有数据时不立刻显示 loading，先静默请求
    const hasData = this.cards.length > 0
    if (!hasData) {
        // 从未加载过数据：直接显示骨架（首次进入属于正常加载）
        this.loading = true
    }
    // 设置一个延迟定时器：300ms 后如果还没返回，显示骨架
    let loadingTimer = null
    if (hasData) {
        loadingTimer = setTimeout(() => {
            this.loading = true
        }, 300)
    }
    try {
        const ps = uniCloud.importObject('pin-system')
        const res = await ps.draw({ count: 5 })
        if (loadingTimer) clearTimeout(loadingTimer)
        if (res.errCode === 0 && res.data) {
            this.cards = res.data.items || []
        }
    } catch (e) {
        if (loadingTimer) clearTimeout(loadingTimer)
        console.error('[pin-topbar] refresh error:', e)
    } finally {
        this.loading = false
    }
}
```

**逻辑：**
- 首次加载（`cards` 为空）→ 直接显示骨架屏（符合用户预期）
- 已有旧数据 → 保持展示旧卡片，300ms 后请求还没返回才切骨架屏
- 请求在 300ms 内返回 → 静默替换数据，用户无感知

### 改 `index.vue` 的 `showGrid` 切换（可选）

用 `key` 属性替代 `v-if` 切换来触发动画，避免中间帧空白：

```html
<view :key="gridKey" class="grid-container">
  <!-- ... -->
</view>
```

```javascript
onShow() {
    if (this.isFirstShow) {
        this.isFirstShow = false
        return
    }
    this.gridKey++ // 触发 Vue 强制重建 DOM，带入场动画
    this.$nextTick(() => {
        this.$refs.pinTopbar?.refresh()
    })
    this.checkUnreadCareer()
},
```
