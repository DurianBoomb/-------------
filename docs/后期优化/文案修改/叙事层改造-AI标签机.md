# 叙事层改造 · AI 标签机

> **一句话概括：** 你做了一份问卷，AI 像一台工业标签打印机一样，给你打出几张标签。这和"测试"无关——没人会觉得超市的价签打印机在"算命"。

---

## 一、为什么选标签机

### 1.1 避开审核雷区

| 审核红线 | 标签机叙事如何避开 |
|---|---|
| 算命/运势预测 | 标签机只扫描已有信息，不预测未来 |
| 伪科学测试 | 这是机器打印，不是心理学评估 |
| 封建迷信 | 全程标注"AI 自动生成""仅供娱乐" |
| 违规内容诱导 | 标签是吐槽文案，不涉及政治/迷信/色情 |

**一句致死量让审核闭嘴：** 「这是一台 AI 标签打印机，用户填问卷，机器吐标签。和算命抽签没有任何关系。」

### 1.2 标签机 vs 测试/鉴定/算命

| 叙事 | 用户预期 | 审核态度 | 分享动力 |
|---|---|---|---|
| 心理测试 | 严肃/专业 | 敏感（伪科学风险） | 中 |
| 算命抽签 | 玄学/迷信 | 高危（封建迷信） | 高 |
| 成分鉴定 | 有趣/半认真 | 中等（边缘擦球） | 高 |
| **标签机** | **有趣/不正经** | **低（纯娱乐工具）** | **极高** |

标签机叙事本质上是一个**工业化机械感的恶搞框架**——越像正经机器就越好笑，越像机器就越不像算命。

## 二、叙事框架总览

### 2.1 世界观设定

你面前有一台「AI 标签机」。它没有感情，不会占卜，不会预测运势。它只会做一件事——读取你的答题内容，然后咔嚓咔嚓吐出几张标签。

**核心隐喻：** 工业标签机 / 收银机 / 快递面单打印机。

- 你给它输入（答题）→ 它扫描 → 它吐出标签 → 你撕下来看看写了什么
- 全程机械感、自动感、毫无神秘可言
- 「标签机可能会出错，标签可能贴歪，标签上的话可能是 AI 胡扯的」

### 2.2 叙事流水线

```
问卷答题 → AI鉴定成分 → 标签机打印标签 → 用户撕下查看 → 贴给别人
   ↑              ↑              ↑              ↑            ↑
 进料口         扫描中         打印中         出标签       贴标签
```

五步流水线，每一步都有对应的视觉和文案。

| 阶段 | 用户动作 | 界面叙事 | 流程文案 |
|---|---|---|---|
| **1. 进料口** | 看到入口 | 「请把你自己放进标签机」 | 「AI标签机已开机」 |
| **2. 扫描中** | 填写问卷 | 「标签机正在扫描你的成分」 | 「扫描中…正在解析第3/10项参数」 |
| **3. 打印中** | 等待生成 | 「标签正在打印，请稍候」 | 「咔嚓咔嚓…标签打印中…」 |
| **4. 出标签** | 看到结果 | 「你的标签已打印，请撕下查看」 | 标签纸的视觉呈现 |
| **5. 贴标签** | 分享 | 「把这张标签贴到群里」 | 「分享标签，让群友也被贴一张」 |

### 2.3 视觉基调

**色调：** 工业感暖灰白底 + 橙色/黄色机械元素（标签纸的黄底、打印机的信号灯）
**质感：** 纸张、贴纸、锯齿边、打印墨水、碳带
**字体：** 标签上的大字用粗等宽或粗宋，小字用细等宽（模拟热敏打印效果）
**动效：** 标签纸"滑出"、锯齿"撕裂"、贴纸"啪"贴上

## 三、标签纸本身的视觉叙事

一张标签不是一段普通文字，而是一张**"标签纸"的视觉呈现**。

### 3.1 标签纸结构

```
┌──────────────────────────────┐
│ ◆ 标签机型号：AX-2026       │  ← 顶部条（灰色细字）
│ ──────────────────────────── │
│                              │
│      【社恐型群友】          │  ← 主标签名（大字居中）
│                              │
│ ──────────────────────────── │
│ 成分说明：                   │  ← 详细吐槽文案
│ AI鉴定结果：此人社交能量    │      （中号字，左对齐）
│ 条极短，但遇到对的人能疯   │
│ 一整天。建议分类存放于安   │
│ 静角落，避免与其他活物混装  │
│ ──────────────────────────── │
│ 打印时间：2026.05.29 14:03  │  ← 底部信息
│ 本标签由AI自动生成，仅供娱乐 │  ← 免责声明
│ ═══════════════════════════  │  ← 锯齿撕纸线
└──────────────────────────────┘
```

### 3.2 设计要素清单

| 要素 | 说明 | 视觉效果 |
|---|---|---|
| **锯齿边（齿孔）** | 标签纸的左右边缘用虚线锯齿 | 强化"撕下来"的触感联想 |
| **底色** | 米白/浅暖灰底（模拟不干胶标签纸） | 比纯白更有纸感 |
| **「已打印」水印** | 标签纸斜向淡色水印 | 暗示自动化生成 |
| **条形码装饰** | 底部加一个装饰性条形码（纯视觉，不编码真实数据） | 强化"机器打印"的工业感 |
| **撕纸线** | 底部一条虚线或锯齿线 | 暗示"撕下来带走" |
| **打印日期戳** | 自动填当前时间 | 增加"这就是刚才打的"的即时感 |

### 3.3 多标签展示

一次鉴定生成 3~5 张标签，每张是独立标签纸，可左右滑动：

- **主标签（1 张）：** 最大最显眼，核心结果（如「社恐型群友」）
- **副标签（2~4 张）：** 较小的补充标签（如「深夜活跃分子」「斗图十级选手」）

视觉上大小区分，主标签占屏幕约 60%，副标签并排或堆叠。

## 五、音频/动效方案（可选增强）

### 5.1 打印音效

标签机叙事天然适合加音效，且音效本身就是"机器在工作"的证据（反证这不是算命）：

- **打印中：** 类似热敏打印机/收银机打印的机械声（嗒嗒嗒嗒嗒+轻微电机声）
- **打印完成：** 一声清脆的"叮"（标签机出票提示音）
- **撕标签：** 纸张撕裂声（用户在结果页查看时触发）

这些音效可以在 manifest.json 中配置静默播放（不打断背景音乐，不强制播放）。

### 5.2 过渡动效

| 阶段 | 动效 |
|---|---|
| 答题 → 等待 | 画面轻微收缩，像被"吸进"标签机 |
| 等待 → 结果 | 一张标签纸从底部滑出（带弹性缓出） |
| 主标签 → 副标签 | 左右滑动，像翻标签纸 |
| 分享 | 标签纸缩小飞出，像被"贴"到聊天里 |

## 六、与现有功能体系的兼容

### 6.1 「鉴定」二字是否保留？

**保留。** 「鉴定」描述的是 AI 判定的**逻辑动作**，不会和标签机冲突。

```
用户视角的感知路径：
  问卷答题 → AI在"鉴定"我 → 鉴定完了 → 标签机"打印"出标签 → 我"撕下来"看
```

「鉴定」是后台工序（用户知道在发生但看不到），「标签」是前台产物（用户看到的就是这个）。

代码层面：所有变量名/数据库字段不需要改。纯粹是文案层+视觉层的替换。

### 6.2 与「15分钟名气档案」体系的关系

两者可以共存，叙事不冲突：

- **标签机**：用户主动来做问卷 → 当场打印标签。即时、轻量、单次。
- **名气档案**：你的问卷被推广到置顶池 → 曝光后生成战绩/名人档案。延时、累积、有分量。

可以理解为：
- 标签机 = 街角的立等可取打印店
- 名气档案 = 名人堂登记处

## 七、审核安全论证

| 审核可能提出的问题 | 标签机叙事的标准答复 |
|---|---|
| 这是心理测试类小程序吗？ | 不是。这是 AI 标签打印机，用户填写偏好后机器自动生成吐槽标签，与心理学无关。 |
| 结果是否涉及运势、命运等内容？ | 不涉及。标签内容是 AI 根据用户选择生成的幽默吐槽文案，不预测未来、不涉及超自然力量。 |
| 是否有封建迷信元素？ | 没有。整个流程模拟工业标签机打印，是科技感+娱乐感的结合，不存在任何迷信叙事。 |
| 用户是否可能误解为真实诊断？ | 所有标签纸上均标注「AI 自动生成，仅供娱乐」。页面底部有完整免责声明。 |
| 标签内容如何确保合规？ | 标签内容为 AI 生成的吐槽式幽默文案，属于创意文学/脱口秀范畴，不涉及政治、色情、迷信等红线主题。 |

### 七.1 可能的风险点及防范

| 风险 | 概率 | 防范措施 |
|---|---|---|
| 用户自己打印的标签名违规（如 UGC 标签） | 低 | 标签名已有前后端敏感词过滤 |
| 审核仍将"成分鉴定"视同为"心理测试" | 低-中 | 标签机叙事作为一种差异化框架，配合"仅供娱乐"的反复标注，已足够区分 |
| 标签纸视觉设计过于像"真的诊断报告" | 低 | 在设计上保持"贴纸""标签纸""打印纸"的廉价工业感，不要做得太精致 |

  mainLabel: "社恐型群友",            // 主标签名（大字居中）
  subLabels: [                         // 副标签数组
    "深夜活跃分子",
    "斗图十级选手"
  ],

## 十、延展想法（不上本期排期）

这些是标签机叙事开出来的脑洞，留作后续参考：

1. **标签贴纸商城：** 用户可以选不同风格的标签纸模板（复古/极简/浮夸/手写风）
2. **互贴标签：** 「让 AI 也给你的群友打印一张标签」→ 裂变入口
3. **标签墙：** 用户被贴过的所有标签排成一面墙，很有视觉冲击力
4. **标签卷纸模式：** 极端的视觉方案——所有标签印在一卷连续的纸上，像收银小票
5. **标签机皮肤：** 不同型号的标签机（老式打字机风/现代极简风/蒸汽朋克风），切换后标签纸样式也变
