# 雷达图优化方案

## 问题

问卷题目数量少（每个维度 3 道题），raw 数据容易出现极端值（0 或 100），直接画雷达图形态怪异。

## 解决思路

**真实数据只用来匹配结果类型，匹配完后用一套"好看"的假数据画雷达图。**

这是个游戏，可以"造假"。

## 造假数据的三个要求

1. **好看**：大部分数据在 40%-70%，符合正态分布，小部分可在此范围外
2. **准确**：结果类型对应的维度得分最高，且至少比其他维度高 20 个百分点
3. **稳定**：同一种结果类型 + 相近的 raw 得分，每次造假数据尽量一致

## 新 goResult() 流程

```
1. 算 raw（0-100）
2. raw → 匹配结果类型
3. raw + 结果类型 → 生成种子 → 造假数据
4. 造假数据 → 雷达图展示（scores 变量）
5. raw → 数据库存真实分（dimensionScores 字段改为 raw）
```

## 种子设计

### 种子构成

```
种子字符串 = 结果类型name + raw加权和分桶编号
```

### 分桶

raw 的 5 个维度取值 0-100，加权和范围 0-500，每 20 一档：

```
分桶编号 = floor(加权和 / 20)
```

最多 25 个桶。同一结果类型下，大部分人的加权和会落在相邻几个桶内。

### 为什么用分桶而不是直接 hash(raw)

- 完全相同的 raw → 完全相同的雷达图（太死板，没解释空间）
- 分桶后：同桶内 raw 不同但雷达图相同，不同桶有细微差异（3-5%）
- 对外解释："做题时的反应速度也会纳入考量"

### 示例

```
用户 A：结果"社交达人"，raw = [82, 35, 60, 28, 70]，加权和 = 275，分桶 = 13
种子字符串 = "社交达人_13"
哈希 → 1849203875

用户 B：结果"社交达人"，raw = [78, 40, 55, 32, 72]，加权和 = 277，分桶 = 13
种子字符串 = "社交达人_13"  ← 相同
哈希 → 1849203875           ← 相同
雷达图完全相同

用户 C：结果"社交达人"，raw = [50, 20, 40, 15, 30]，加权和 = 155，分桶 = 7
种子字符串 = "社交达人_7"   ← 不同
哈希 → 73829104             ← 不同
雷达图形状相似但细节有 3-5% 差异
```

## 造假数据生成算法

### 完整流程

```javascript
generateFakeScores(raw, resultType, dims) {
  // 1. 构建种子
  const rawSum = raw.reduce((a, b) => a + b, 0)
  const bucket = Math.floor(rawSum / 20)
  const seedStr = resultType.name + '_' + bucket
  const seed = hashString(seedStr) // 字符串哈希为 32 位整数

  // 2. 用种子初始化伪随机数生成器
  const rng = createSeededRNG(seed)

  // 3. 生成 5 个维度的正态分布初始值
  //    ~N(55, 12), clamp [20, 70]
  const fake = dims.map(() => {
    const val = boxMuller(rng, 55, 12)
    return Math.max(20, Math.min(70, Math.round(val)))
  })

  // 4. 确定主维度（match 字段对应的维度索引）
  const mainIdx = dims.indexOf(resultType.match)

  // 5. 用种子 + 主维度标记生成 75-85 的主维度值
  const mainRng = createSeededRNG(seed ^ 0x5A77) // XOR 偏移确保独立序列
  const mainVal = 75 + Math.floor(mainRng() * 11) // 75-85

  // 6. 设置主维度
  fake[mainIdx] = mainVal

  // 7. 修正：确保主维度至少比其他人高 20
  const threshold = mainVal - 20
  for (let i = 0; i < fake.length; i++) {
    if (i !== mainIdx && fake[i] >= threshold) {
      fake[i] = threshold - 1
    }
  }

  // 8. 兜底：如果主维度不是最高的（理论上不会，但防守）
  const maxOther = Math.max(...fake.filter((_, i) => i !== mainIdx))
  if (fake[mainIdx] <= maxOther) {
    fake[mainIdx] = maxOther + 21
  }

  return fake
}
```

### 步骤说明

| 步骤 | 说明 |
|------|------|
| 1-2 | 种子 → 确定性随机数生成器 |
| 3 | 正态分布生成初值，大部分在 40-70 |
| 4 | 从 resultType.match 拿主维度 |
| 5 | 主维度固定 75-85，保证突出 |
| 6-7 | 替换主维度 + 压超标项 |
| 8 | 兜底检查 |

### 效果

- 雷达图：四个维度在 40-70 自然分布，一个维度在 75-85 突出
- 同一结果类型 + 同一分桶：完全相同的雷达图
- 同一结果类型 + 不同分桶：形状相似，细微差异

### 新增工具函数

需要添加到 `answer-quiz.vue` 的 methods 中：

1. **`hashString(str)`**：字符串哈希为 32 位整数
2. **`createSeededRNG(seed)`**：基于种子的伪随机数生成器（返回 0-1 的函数）
3. **`boxMuller(rng, mean, stddev)`**：Box-Muller 变换生成正态分布
4. **`generateFakeScores(raw, resultType, dims)`**：主函数

### 种子确定性实现

```javascript
// 简单的字符串哈希（djb2 算法）
hashString(str) {
  let hash = 5381
  for (let i = 0; i < str.length; i++) {
    hash = ((hash << 5) + hash + str.charCodeAt(i)) | 0
  }
  return hash >>> 0
}

// 基于种子的简易 PRNG（mulberry32 算法）
createSeededRNG(seed) {
  let s = seed | 0
  return function() {
    s |= 0
    s = s + 0x6D2B79F5 | 0
    let t = Math.imul(s ^ s >>> 15, 1 | s)
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t
    return ((t ^ t >>> 14) >>> 0) / 4294967296
  }
}

// Box-Muller 正态分布生成
boxMuller(rng, mean, stddev) {
  let u1, u2
  do { u1 = rng() } while (u1 === 0)
  u2 = rng()
  const z = Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2)
  return mean + z * stddev
}
```
