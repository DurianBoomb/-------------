## 二层：真机一键 Mock 测试（已实现）

**页面**：`pages-tools/phase2-test/phase2-test`  
**入口**：`quiz-home.vue` 顶部右侧 🛠️ 按钮（橙色边框）  
**前置**：云函数 `survey` 已上传部署  

### 测试流程

| 编号 | 测试项 | 调用的云函数方法 | 预期结果 |
|------|--------|-----------------|---------|
| T1 | getTagList 字段完整性 | `getTagList` | 每条标签含 `creatorId/source/surveyId` |
| T2 | user 标签 creatorNickname | `getTagList` | user 标签有 `creatorNickname` 且值非空 |
| T3 | 非 user 标签无昵称 | `getTagList` | system/coze 标签的 `creatorNickname` 为空串 |
| T4 | 生成 → 标签入池 | `generateFromCoze` → `getTagList` | 新标签出现在标签池，source=user，rarity=handmade1，surveyId 正确 |
| T5 | 重建 → 更新 surveyId | `generateFromCoze` ×2 | 同用户重建后标签池仅 1 条，surveyId 已更新 |

**注意**：T4/T5 需要登录 + Coze 有额度，如果未登录会自动跳过生成测试。

### 操作步骤

1. 确保云函数 `survey` 已上传部署
2. 在小程序中打开 quiz-home 首页
3. 点击顶部 🛠️ 按钮进入测试页
4. 点击「一键自动测试」
5. 观察日志，确认 5 项全部通过

**也可以**：
- 点击「仅测标签列表」→ 只测 T1/T2/T3（不需要 Coze 额度）
- 点击「仅测生成」→ 只测 T4（需要 Coze 额度）

## 四层：边界条件真机验证

| 编号 | 场景 | 操作 | 预期 |
|------|------|------|------|
| B1 | 未登录用户看标签池 | 退出登录 → 打开 quiz-home | getTagList 正常返回，user 标签的 creatorNickname 为空 |
| B2 | 用户无昵称 | 把昵称清空 → 生成问卷 | getTagList 中该标签 creatorNickname 为空串 |
| B3 | Coze 额度耗尽 | 疯狂点生成直到用完 | 问卷不入 surveys；标签池不受影响（fire-and-forget 不阻塞） |
| B4 | 网络中断 | 生成过程中切飞行模式 | 前端正常报错不崩溃；标签池无脏数据 |
| B5 | 同用户多次重建同名标签 | 对同一标签点 3 次生成 | 标签池始终 1 条，surveyId 指向最新问卷 |
| B6 | 不同用户生成同名标签 | 账号 A 生成「测试X」→ 账号 B 也生成「测试X」 | 账号 B 被 `TAG_ALREADY_EXISTS` 拒绝（阶段三会放开） |
