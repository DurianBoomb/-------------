## 二层：真机一键 Mock 测试

**页面**：`pages-tools/phase1-clickcount-test/phase1-clickcount-test`
**入口**：`quiz-home.vue` 顶部 🛠️ 旁新增按钮
**前置**：云函数 `survey` 已上传部署

### 测试流程

| 编号 | 测试项 | 调用的云函数方法 | 预期结果 |
|------|--------|-----------------|---------|
| T1 | 数据迁移 | `migrateShareCountToClickCount()` | 统计迁移/跳过数量 |
| T2 | surveys clickCount 字段存在 | `getSurveyByTag({ tagName: '群友成分鉴定' })` | 返回含 `clickCount` 字段 |
| T3 | surveys source 字段存在 | `getSurveyByTag({ tagName: '群友成分鉴定' })` | 系统预置问卷 source 为空或不存在 |
| T4 | survey-tags clickCount 字段 | `getTagList({ pageSize: 5 })` | 标签含 `clickCount` 字段 |
| T5 | generateFromCoze 含新字段 | `generateFromCoze({ tagName })` | 返回问卷含 `source: 'coze'` 和 `clickCount: 0` |
| T6 | 迁移后数据一致性 | 迁移后查标签 clickCount | 迁移值与旧 shareCount 一致 |

### 操作步骤

1. 部署 Schema 和云函数
2. 打开小程序 → quiz-home → 点击阶段一测试入口
3. 点击「🚀 一键运行全部」
4. 观察日志，确认全部通过
5. 点击「执行数据迁移」调用 `migrateShareCountToClickCount()`
6. 迁移后再次运行 T4/T6 验证

---

## 三层：数据迁移手动验收

| 编号 | 验收项 | 操作 | 验收标准 |
|------|--------|------|---------|
| M1 | 迁移按钮可执行 | 点击「执行数据迁移」 | 日志显示迁移/跳过数量 |
| M2 | 迁移后重复执行幂等 | 再次点击迁移 | 第二次 migrated=0，skipped=全部 |
| M3 | 旧 shareCount 值正确迁移 | 对比迁移前后 clickCount 值 | clickCount >= 旧 shareCount 值 |

---

## 四层：边界验证

| 编号 | 场景 | 预期 |
|------|------|------|
| B1 | surveys 表中所有预置问卷 clickCount 默认为 0 | `getSurveyByTag` 返回 clickCount=0 |
| B2 | 新生成的 user 问卷 source=coze, clickCount=0 | `generateFromCoze` 返回正确 |
| B3 | survey-tags 中无 shareCount 的历史标签 | 迁移跳过，clickCount 保持默认 0 |
| B4 | 未登录调用 getSurveyByTag | 正常返回（read 权限公开）|

## 快速执行顺序

```
1. node test_phase1_clickcount.js   → 本地 Schema 结构验证
2. 上传 Schema + 云函数               → 部署阶段一代码
3. 小程序打开 phase1-clickcount-test → 点击「一键运行全部」
4. 点击「执行数据迁移」               → 执行 migrateShareCountToClickCount()
5. 再跑一次 T4/T6                     → 验证迁移后数据一致性
6. 在 quiz-home 标签池目视确认        → 标签 clickCount 正常显示（后续阶段）
```
