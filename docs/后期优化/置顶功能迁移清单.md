#### g) 性能注意事项

**`checkCareerStatus()` 缓存优化**（设计文档 §7.2.1）：
- `onShow` 在微信小程序中触发频繁，建议在 `checkUnreadCareer` 入口加本地缓存判断：

- `pinTopbar` 组件的 `refresh()` 方法内部调用 `pinSystem.draw()`（设计文档 §4.6 抽取接口 + §6.2 展示规则）。
- quiz-home 自身不需要直接调用 `draw`，通过 `pinTopbar.refresh()` 间接触发即可。

## 三、待定问题（已解决）

1. **`currentSurveyId`**：关联 quiz-home 页面当前正在展示/编辑的问卷 ID。
   - 设计文档中 `surveyId` 是贯穿整个置顶链路的核心参数（`handleAdReward` 入参、`enterPool` 参数等），它就是"用户正在操作的那份问卷的 ID"。
   - 在 quiz-home 页面中，这个 ID 即页面当前展示的问卷 ID。需确认 quiz-home 现有逻辑通过什么方式拿到当前问卷 ID（页面参数、data 属性、store/缓存），直接把那个值赋给 `currentSurveyId`。

2. **未读档案弹窗**：**一并迁移到 quiz-home。**
   - 设计文档 §7.2.1 原文："用户进入**问卷工具首页**时，首页 `onShow` 生命周期调用云对象方法 `checkCareerStatus()`""用户自然回流首页时弹窗"。
   - 文档中的"首页"指的是问卷工具的首页。迁移后，这个首页就是 **quiz-home.vue**，不是 index.vue。
   - 文件已更新为同时迁移未读档案弹窗（见下方补充清单）。

3. **index.vue 删除 `components` 后**：直接删掉 `components` 这个 key，Vue 允许。不必保留空对象。
