## 二、视觉规格速查

| 稀有度 | 标签云颜色 | 标签云字号 | 迷你标签颜色 | 迷你标签字号 |
|--------|-----------|-----------|-------------|-------------|
| common  | #101828 灰黑 | 22rpx | #101828 | 22rpx |
| rare    | #4FC3F7 浅蓝 | 26rpx | #4FC3F7 | 22rpx |
| **mythic** | **#22C55E 绿色** | **26rpx** | **#22C55E** | **22rpx** |

> mythic 在标签云中和 rare 尺寸一致（二等稀有度），颜色用绿色区分。
> legendary 在标签云中和 epic 尺寸一致（一等稀有度），颜色用红色区分。

## 三、迁移时的注意事项

1. **必须 4 件一起迁移**：schema + init_data + quiz-home.vue + result.vue，少任何一个都会导致样式缺失。

2. **schema 同步后需要重新导入 init_data**：如果 release 上数据库之前没接受 mythic/legendary，那这些标签根本不在库里，前端拿到空数据自然不会有对应标签出现。

3. **没有额外需要迁移的逻辑**：标签云的 `classStr` 是动态拼接 `'tag-' + rarity`，迷你标签也是 `'mini-' + rarity`，只要 CSS 存在就能自动匹配。

4. **darkgold 不是问题**：release 上如果 darkgold 正常显示，说明 CSS class 拼接机制本身没问题——问题纯粹是 mythic/legendary 相关的代码不存在。
