# 结果页图片预加载

## 问题

结果页结果类型有图片时，加载慢，用户会看到短暂空白。

## 原因

原逻辑只在 `goResult()` 中调用 `uniCloud.getTempFileURL()` 把 `cloud://` 转成临时 HTTPS 链接，并未实际下载图片。真正下载发生在结果页 `<image>` 组件渲染时。

## 方案

在答题页 `goResult()` 中，解析完 cloud URL 之后、`redirectTo` 之前，用 `uni.getImageInfo()` 把图片下载到微信本地缓存。

- `uni.getImageInfo()` 在微信小程序里会触发图片下载并写入本地缓存
- 后续 `<image>` 组件请求同一 URL 时直接读缓存，无需网络请求
- `fail` 回调里不阻塞跳转，结果页有 emoji 兜底

## 缓存清理

微信对 `getImageInfo` 下载的图片缓存有自动回收策略：

- 存储空间紧张时自动清理旧缓存
- 小程序被销毁/切后台时可能清理
- 有总量上限（一般几 MB 到几十 MB）

单张结果图几十 KB，用户答题频率远不到触发清理阈值，不需要开发者手动清理。

## 改动位置

`pages-tools/answer-quiz/answer-quiz.vue` - `goResult()` 方法，`getTempFileURL` 之后、`redirectTo` 之前。
