```
输入: "社交达人_13" vs "社交达人_14"

```

### 1.3 hashString — 空字符串

```
输入: ""
预期: 返回某个确定性整数（djb2 初始值 5381 的处理结果），不抛异常
```

### 1.4 createSeededRNG — 确定性

```
给定 seed = 12345，生成前 10 个数
验证: 两个独立 createSeededRNG(12345) 实例的前 10 个数完全一致
```

### 1.5 createSeededRNG — 范围

### 1.7 boxMuller — 正态分布统计

### 2.5 主维度最高

## 第六轮：特殊问卷（profile 向量匹配）

### 核心差异

| | 普通问卷 | 特殊问卷 |
|---|---|---|
| 结果匹配 | 取 raw 最高维度 → `match` 字段 | raw 与所有 `profile` 的欧几里得距离 → 取最近 |
| 造假策略 | `generateFakeScores` — 正态分布 + 一个尖刺 | `generateFakeScoresByProfile` — **按 profile 比例缩放**整个形状 |
| 主维度来源 | `resultType.match` | `profile` 中值最大的索引 |
| 非主维度形状 | 随机（N(55,12)） | 跟随 profile 比例关系 |

**profile 值域：`[0, 100]`，与 raw 同量纲。** 欧几里得距离计算无需归一化，直接相减即可。

### 结果匹配算法

```
raw = [82, 45, 67, 30, 91]       ← 用户答题真实分

遍历所有 resultTypes：
  profile_A = [90, 40, 60, 20, 85]  → dist = sqrt((90-82)² + (40-45)² + ...) = 12.8
  profile_B = [30, 85, 50, 70, 20]  → dist = sqrt((30-82)² + (85-45)² + ...) = 96.3
  ...

距离最小者命中 → result = profile_A 对应的结果类型
```

**判断条件：** `resultTypes[0].profile` 是否存在。一个问卷要么全是普通类型、要么全是特殊类型，看第一个就够了。

### generateFakeScoresByProfile 算法

```
输入: raw = [82, 45, 67, 30, 91]
      resultType = { name: "社交达人", profile: [90, 40, 60, 20, 85] }
      dims = ["社交", "冒险", "智力", "创意", "共情"]

步骤 1: 构建种子（与普通问卷一致）
  rawSum = 82+45+67+30+91 = 315
  bucket = floor(315/20) = 15
  seedStr = "社交达人_15"
  seed = hashString(seedStr)

步骤 2: profile 线性映射到 [30, 70]
  profile 值域 [0, 100]，pMin/pMax 天然在此区间内
  pMin = min(profile) = 20
  pMax = max(profile) = 90
  映射: fake[i] = 30 + (profile[i] - pMin) / (pMax - pMin) * 40
  → [70, 41, 53, 30, 67]

步骤 3: 主维度（profile 最大值索引 0）→ 种子生成 75-85
  mainRng = createSeededRNG(seed ^ 0x5A77)
  mainVal = 75 + floor(mainRng() * 11)  →  82
  → [82, 41, 53, 30, 67]

步骤 4: 非主维度加种子噪声 ±3
  noiseRng = createSeededRNG(seed ^ 0x3CAD)
  fake[i≠0] += round((noiseRng() - 0.5) * 6)
  → [82, 39, 55, 32, 64]

步骤 5: clamp [20, 70] 非主维度
  → [82, 39, 55, 32, 64]  (全部在范围内)

步骤 6: gap ≥ 20 修正
  threshold = 82 - 20 = 62
  64 ≥ 62 → fake[4] = 61
  → [82, 39, 55, 32, 61]

步骤 7: 兜底检查 mainIdx 是否最高
  maxOther = 61, mainVal = 82 > 61 ✓

输出: [82, 39, 55, 32, 61]
```

**关键：** 雷达图形状 = profile 的等比例缩放 + 种子噪声，不是随机的。高 profile 值的维度在高分区、低值在低分区。profile 与 raw 同为 0-100 空间，距离计算无需量纲统一。

### 6.1 确定性 — 相同 profile + 同 bucket 同输出

```
profile = [90, 40, 60, 20, 85], name = "社交达人"
rawA → rawSum = 315, bucket = 15
rawB → rawSum = 312, bucket = 15
验证: generateFakeScoresByProfile(rawA, ...) === generateFakeScoresByProfile(rawB, ...)
```

### 6.2 形状保真 — fake 排序 = profile 排序

```
给定 profile = [90, 40, 60, 20, 85]
profile 排序: 索引 0 > 4 > 2 > 1 > 3
fake 排序应满足: 索引 0 > 4 > 2 > 1 > 3（允许噪声导致相邻值微调但整体趋势不变）
验证: fake 的皮尔逊相关系数与 profile ≥ 0.85
```

### 6.3 主维度约束同普通问卷

```
主维度范围 [75, 85]
非主维度范围 [20, 70]
gap ≥ 20
验证: 全覆盖（26×N 个 resultType）通过
```

### 6.4 噪声不影响排序

```
遍历多个剖面 + bucket
验证: 噪声 ±3 不会使低 profile 维度反超高 profile 维度（差值 ≥ 5 的维度对）
```

### 6.5 边界 — profile 平顶（多个相同最高值）

```
profile = [90, 90, 50, 40, 60]
两个维度同时最高 → indexOf 取第一个为 mainIdx
验证: 两个平顶维度中至少一个是最高，另一个可能被步骤 6/7 压低
```

### 6.6 边界 — profile 全相等

```
profile = [50, 50, 50, 50, 50]
验证: 主维度 75-85，其余在 [20, 70]（线性映射失效 → 需要兜底 fallback 到随机分布）
```

### 6.7 结果匹配用 raw

```
构造 raw 使某 profile 的欧几里得距离最小
验证: result 命中该 profile，与其他 profile 无关
```

### 6.8 goResult 分支

```
resultTypes[0].profile 存在 → 走向量匹配 + generateFakeScoresByProfile
resultTypes[0].profile 不存在 → 走单维度匹配 + generateFakeScores
验证: 两种路径 scores 和 dimensionScores 数据正确
```

## 实现清单

### 新增函数

`generateFakeScoresByProfile(raw, resultType, dims)` — profile 比例缩放版

### 修改函数

`goResult()` — 结果匹配和造假分支：

```javascript
// goResult() 完整流程
async goResult() {
    const raw = dims.map(d => cnts[d] ? ((sums[d] / cnts[d] - 1) / 2) * 100 : 50)

    let result
    let scores

    if (this.survey.resultTypes[0]?.profile) {
        // === 特殊问卷：欧几里得距离匹配 ===
        const distances = this.survey.resultTypes.map(rt => {
            const sumSq = rt.profile.reduce((acc, p, i) => acc + Math.pow(p - raw[i], 2), 0)
            return Math.sqrt(sumSq)
        })
        const minIdx = distances.indexOf(Math.min(...distances))
        result = this.survey.resultTypes[minIdx]
        scores = this.generateFakeScoresByProfile(raw, result, dims)
    } else {
        // === 普通问卷：取最高维度匹配 ===
        const topDim = dims.reduce((a, b) => raw[dims.indexOf(a)] >= raw[dims.indexOf(b)] ? a : b)
        result = this.survey.resultTypes.find(r => r.match === topDim) || this.survey.resultTypes[0]
        scores = this.generateFakeScores(raw, result, dims)
    }

    const dimensionScores = {}
    dims.forEach((d, i) => { dimensionScores[d] = raw[i] })

    // submitAnswer + redirectTo 不变
}
```
