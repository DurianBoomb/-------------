## 三、手动验收清单（前端）

| 编号 | 验收项 | 操作步骤 | 验收标准 |
|------|--------|---------|---------|
| M1 | quiz-home → answer-quiz 传 surveyId | 在标签池点击一个 user 标签 | 跳转 URL 含 `&surveyId=xxx` |
| M2 | answer-quiz onLoad 解析 surveyId | 进入答题页 | 网络请求 `getSurveyByTag` 的 payload 含 `surveyId` |
| M3 | answer-quiz 分享含 surveyId | 答题页右上角分享 | 分享路径含 `&surveyId=xxx` |
| M4 | result 分享含 surveyId | 结果页点击「贴出去」 | 分享路径含 `&surveyId=xxx` |
| M5 | 旧分享链接兼容（无 surveyId） | 构造不带 `surveyId` 的分享链接打开 | 正常加载问卷（走 `where({ tagName })` 兜底） |
| M6 | 同名不同用户不冲突 | 用户 A 和用户 B 各自生成同名标签 | 两者都能正常答题，不会被拒绝 |
