## 四、核心数据链路

### 4.1 数据结构（Coze 友好版）

```javascript
{
  tag: '确诊为烤肠',           // 标签名
  title: '你被确诊为什么东西？',   // 页面标题
  dims: ['淀粉含量', '加肉程度', ...],  // 3-7个维度（纯字符串）
  qs: [
    { title: '周末你更倾向于一个人待着？', dim: '淀粉含量' },
    // ... 维度数 × 3 道题，每题指定维度
  ],
  resultTypes: [
    { name: '纯正淀粉肠', emoji: '🌭', desc: '...', match: '淀粉含量' },
    // match 写维度名字符串，前端算分后匹配最高维度
  ]
}
```

**关键约定**：
- Coze 只写文字，不碰任何数学（分值、索引、prototypes）
- 每题 3 个固定选项（反对/中立/同意），前端自动映射 1/2/3 分
- 每题通过 `dim` 字段关联到维度
- 结果匹配：计算每个维度平均分 → 归一化 0-100 → 最高分维度 → 匹配 `match` 字段

### 4.2 评分逻辑（答题页 `goResult()`）

1. 每题记录 `{ dim: '维度名', score: 1/2/3 }`
2. 每个维度取平均分 → `((avg - 1) / 2) * 100` 归一化到 0-100
3. 最高分维度匹配 `resultTypes[].match`
4. 加统一偏移噪声（±5）美化雷达图显示
5. 跳转到结果页传递参数

### 4.3 魔改问卷库

当前 mock 问卷：
- `确诊为烤肠`：5 维度 × 3 题 = 15 题
- `搬屎大王`：4 维度 × 3 题 = 12 题
- 数据写在 `pages-tools/answer-quiz/answer-quiz.vue` 的 `MOCK_QUIZ` 里

## 六、已知 Bug & 踩坑记录

详见 `docs/踩坑记录-动画移植.md`：

1. **scroll-view padding 不生效** → 内套 `body-inner` 容器
2. **animation 和 hover-class transform 冲突** → DOM 分层：外层按压，内层动画
3. **小程序 `:key` 表达式不支持** → 用 `:key="'prefix-' + idx"` 字符串拼接
4. **`?.` 可选链 WXML 不支持** → 用 `curQ.title` 而非 `curQ?.title`
