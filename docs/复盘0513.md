### 1. Token 校验问题排查（核心阻塞，已解决）

**问题：** survey 云函数 `checkToken` 一直解不出 uid，用户画像/收藏/历史三个页面全部不可用。

**排查过程：**
- 尝试 `_resolveUid()` 作为云对象方法 → uniCloud 框架过滤了 `_` 开头的方法（只保留 `_before`/`_after`），报 `not a function`
- 改名 `resolveUid()` 仍失败 → 云对象框架只暴露外部可调 API 方法，内部 helper 被代码生成器过滤
- 最终方案：`resolveUid` 移到 `module.exports` **外部**作为普通函数，通过传 `this` 调用
- 同时按官方文档修正了三个细节：
  - `createInstance({ context: this })` → `createInstance({ clientInfo: this.getClientInfo() })`
  - 手动取 `ci.uniIdToken` → `this.getUniIdToken()` 官方方法
  - 判断 `payload.uid` → 判断 `errCode === 0`
- 参考 `uni-stat-receiver` 已验证方案：创建实例和校验一步完成

**结果：成功恢复。** 用户画像/收藏列表/答题历史/首页收藏状态全部正常加载。
