# 问卷数据结构规范 · Coze 友好版

> 目标：让 Coze（或其他 AI）能不涉及任何数学运算，仅凭自然语言生成完整的测试卷。

---

## 一、完整数据结构

```javascript
{
  // 标签名（用于搜索匹配）
  tag: '确诊为烤肠',
  
  // 页面标题
  title: '你被确诊为什么东西？',
  
  // 维度列表（3-7 个）
  // Coze 只写字符串名，不需要索引或分值
  dims: ['淀粉含量', '加肉程度', '受欢迎度', '性价比', '抗造性'],
  
  // 题目列表（维度数 × 3）
  // 每道题包含文本 + 所属维度名
  qs: [
    { title: '周末你更倾向于一个人待着？', dim: '淀粉含量' },
    { title: '你喜欢在背后默默吐槽？', dim: '加肉程度' },
    // ...
  ],
  
  // 结果类型（每个维度对应一个结果，数量必须与 dims 一致）
  resultTypes: [
    { name: '纯正淀粉肠',     emoji: '🌭', emojiBg: '#FFE4B5', desc: '...', match: '淀粉含量' },
    { name: '货真价实肉肠',   emoji: '🍖', emojiBg: '#FFD6C8', desc: '...', match: '加肉程度' },
    { name: '人气爆款',       emoji: '⭐', emojiBg: '#FFF3C4', desc: '...', match: '受欢迎度' },
    { name: '经济实惠肠',     emoji: '💰', emojiBg: '#C8F7C5', desc: '...', match: '性价比' },
    { name: '铁骨铮铮肠',     emoji: '🛡️', emojiBg: '#D6E4FF', desc: '...', match: '抗造性' }
  ]
}
```

## 二、Coze 不需要写的东西

| 不需要写 | 原因 |
|---------|------|
| 数字索引、分数、权重 | 前端自动算 |
| 选项文案 | 从 8 套固定模板随机分配 |
| 原型向量 | 改为按最高维度匹配 |
| 维度对应关系表 | 每题直接用 `dim: '维度名'` 标注 |

## 三、前端运行时自动完成的工作

### 3.1 选项生成
8 套固定选项模板，每次页面加载随机选一套，每套 3 个选项对应 1/2/3 分：

```
选项索引 0 → 反对 → 1 分
选项索引 1 → 中立 → 2 分
选项索引 2 → 同意 → 3 分
```

每 3 题切换一次选项模板。

### 3.2 评分计算
```
每个维度的得分 = 该维度所有题目的平均分
归一化：((平均分 - 1) / 2) × 100  →  范围 0-100
```

### 3.3 结果匹配
```
1. 找出得分最高的维度
2. 遍历 resultTypes，匹配 match === 最高维度名的那个
3. 如果没有匹配到，取第一个 resultType 作为兜底
```

### 3.4 雷达图
- 维度名作为标签
- 各维度 0-100 分数作为数据
- Canvas 2D 绘制，easeOutBack 弹性入场动画

## 四、Coze 写题示例

Coze 输出的 JSON 应该只包含以下字段：

```javascript
{
  tag: '社恐等级测试',           // 必填
  title: '你的社恐等级是多少？',  // 必填
  dims: ['社交恐惧', '回避倾向', '内心戏'],  // 必填, 3-7个
  qs: [
    { title: '在电梯里遇到同事你会假装看手机', dim: '社交恐惧' },
    { title: '你更倾向于发微信而不是打电话', dim: '社交恐惧' },
    { title: '你经常因为担心说错话而选择沉默', dim: '社交恐惧' },
    { title: '聚会时你更希望自己是个透明人', dim: '回避倾向' },
    { title: '你经常找理由推掉社交邀请', dim: '回避倾向' },
    { title: '在路上看到熟人你会绕道走', dim: '回避倾向' },
    { title: '睡前你会复盘今天说过的每句话', dim: '内心戏' },
    { title: '别人随口一句话你能琢磨三天', dim: '内心戏' },
    { title: '你经常在脑子里预演各种对话场景', dim: '内心戏' }
  ],
  resultTypes: [
    { name: '社恐初级', emoji: '😊', emojiBg: '#FFE4B5', desc: '你只是有点内向而已……', match: '社交恐惧' },
    { name: '社恐晚期', emoji: '😰', emojiBg: '#FFD6C8', desc: '你已经病入膏肓了……', match: '回避倾向' },

```

每维度 3 题，3 个维度共 9 题。每个 `resultType` 的 `match` 对应一个维度名。

## 五、验证规则

Coze 输出的 JSON 在前端加载时会做以下检查：

- `dims.length` 是否在 3-7 之间
- `qs.length` 是否等于 `dims.length × 3`
- 每题 `dim` 是否在 `dims` 数组中
- `resultTypes.length` 是否等于 `dims.length`（每个维度对应一个结果）
- 每个 `resultTypes.match` 是否在 `dims` 数组中

不符合规则的试卷使用兜底 mock 数据展示，并提示"试卷格式有误"。
