# 静默注册与多端账号互通开发文档

> 涵盖**微信小程序**和 **QQ 小程序**的无感静默注册，以及**多平台账号互通绑定**

---

## 一、背景

微信小程序和 QQ 小程序的 `login()` API 都可以在用户无感知的情况下获取临时 code，后端用 code 向平台服务器换取 openid，从而实现自动注册/登录。

本方案让用户打开小程序即自动完成账号注册与登录，全程无需授权弹框。如需多端互通，用户主动绑定后，微信和 QQ 入口指向同一账号。

---

## 二、原理

### 2.1 静默注册/登录

```
小程序启动
    │
    ├─ 检查本地 uni_id_token（未过期）
    │     └─ 有 → 跳过
    │
    └─ 没有有效 token
          │
          ├─ uni.login({ provider: 'weixin' | 'qq' })    ← 无感
          │     └─ 返回临时 code
          │
          ├─ 调 uni-id-co.loginByWeixin({ code })   （微信）
          │  或 uni-id-co.loginByQQ({ code })         （QQ）
          │     │
          │     ├─ openid 不存在 → 自动创建 uni-id-users 记录（register）
          │     └─ openid 已存在 → 直接登录（login）
          │
          └─ 返回 token + uid，写入 storage
```

### 2.2 多端账号互通（绑定）

```
用户先通过微信静默登录（已有 uid）
    │
    └─ 在设置页点击"绑定QQ"
          │
          ├─ uni.login({ provider: 'qq' })       ← 无感
          │     └─ 返回 QQ 的 code
          │
          └─ 调 uni-id-co.bindQQ({ code })
                │
                └─ 该 QQ openid 被挂到当前微信账号下
                      └─ 以后不管从微信还是 QQ 进，都是同一个人
```

uni-id-users 表原生支持一个账号绑定多个平台（`wx_openid`、`qq_openid` 等字段），无需改数据库。

## 三、前置条件

### 3.1 微信小程序

| 配置项 | 位置 | 说明 |
|--------|------|------|
| AppID | `manifest.json > mp-weixin > appid` | `wx49daec5e2229d643` |
| AppSecret | `uni-config-center/uni-id/config.json > mp-weixin > oauth > weixin > appsecret` | 从[微信公众平台](https://mp.weixin.qq.com)获取 |
| 微信登录启用 | `uni-id-pages/config.js > loginTypes` | 包含 `'weixin'` |

### 3.2 QQ 小程序

| 配置项 | 位置 | 说明 |
|--------|------|------|
| AppID | `manifest.json > mp-qq > appid` | 从 [QQ 小程序平台](https://q.qq.com)获取 |
| AppSecret | `uni-config-center/uni-id/config.json > mp-qq > oauth > qq > appsecret` | 同上 |
| QQ 登录启用 | `uni-id-pages/config.js > loginTypes` | 取消注释 `'qq'` |

### 3.3 uni-id-co 就绪

两个云对象方法已内置在 `uni-id-co` 中（位于 `uni_modules/uni-id-co/`），无需额外开发：

- `login-by-weixin.js` — 微信静默注册/登录 + 自动创建账号
- `login-by-qq.js` — QQ 静默注册/登录 + 自动创建账号
- `bind-qq.js` — 为当前账号绑定 QQ openid

## 四、微信静默注册（已实现）

### 4.1 `App.vue — onLaunch`

```js
onLaunch() {
    // ... 已有初始化代码
    uniIdPageInit()

    // #ifdef MP-WEIXIN
    this.silentLogin()
    // #endif

    // ... 其他端逻辑
}
```

### 4.2 `App.vue — methods`

```js
methods: {
    // #ifdef MP-WEIXIN
    async silentLogin() {
        // 1. token 存在且未过期则跳过
        const token = uni.getStorageSync('uni_id_token')
        const tokenExpired = uni.getStorageSync('uni_id_token_expired') || 0
        if (token && tokenExpired > Date.now()) return
        if (token) {
            uni.removeStorageSync('uni_id_token')
            uni.setStorageSync('uni_id_token_expired', 0)
        }

        try {
            // 2. 无感拿 code
            const loginResult = await uni.login({ provider: 'weixin' })
            const loginRes = Array.isArray(loginResult) ? loginResult[1] : loginResult
            if (!loginRes || !loginRes.code) {
                console.warn('[静默注册] uni.login 未返回 code')
                return
            }

            // 3. 注册/登录
            const uniIdCo = uniCloud.importObject('uni-id-co', { customUI: true })
            const res = await uniIdCo.loginByWeixin({ code: loginRes.code })

            // 4. 更新状态
            if (res.errCode === 0 || res.errCode === 'uni-id-account-exists') {
                mutations.setUserInfo(res.userInfo || {}, { cover: true })
                uni.$emit('uni-id-pages-login-success')
                console.log('[静默注册] 成功', res.type)
            } else {
                console.warn('[静默注册] 登录失败', res.errCode, res.errMsg)
            }
        } catch (e) {
            console.warn('[静默注册] 异常', e.message)
        }
    }
    // #endif
}
```

## 五、QQ 静默注册（待扩展）

在 `App.vue` 的 `silentLogin` 方法中，用条件编译添加 QQ 分支：

```js
methods: {
    async silentLogin() {
        const token = uni.getStorageSync('uni_id_token')
        const tokenExpired = uni.getStorageSync('uni_id_token_expired') || 0
        if (token && tokenExpired > Date.now()) return
        if (token) {
            uni.removeStorageSync('uni_id_token')
            uni.setStorageSync('uni_id_token_expired', 0)
        }

        try {
            // ★ 微信分支
            // #ifdef MP-WEIXIN
            const loginResult = await uni.login({ provider: 'weixin' })
            const loginRes = Array.isArray(loginResult) ? loginResult[1] : loginResult
            if (!loginRes || !loginRes.code) return
            const uniIdCo = uniCloud.importObject('uni-id-co', { customUI: true })
            const res = await uniIdCo.loginByWeixin({ code: loginRes.code })
            // #endif

            // ★ QQ 分支
            // #ifdef MP-QQ
            const loginResult = await uni.login({ provider: 'qq' })
            const loginRes = Array.isArray(loginResult) ? loginResult[1] : loginResult
            if (!loginRes || !loginRes.code) return
            const uniIdCo = uniCloud.importObject('uni-id-co', { customUI: true })
            const res = await uniIdCo.loginByQQ({ code: loginRes.code })
            // #endif

            // 统一处理结果
            if (res.errCode === 0 || res.errCode === 'uni-id-account-exists') {
                mutations.setUserInfo(res.userInfo || {}, { cover: true })
                uni.$emit('uni-id-pages-login-success')
                console.log('[静默注册] 成功', res.type)
            } else {
                console.warn('[静默注册] 登录失败', res.errCode, res.errMsg)
            }
        } catch (e) {
            console.warn('[静默注册] 异常', e.message)
        }
    }
}
```

> **注意：** `#ifdef MP-WEIXIN` 和 `#ifdef MP-QQ` 是互斥的条件编译，同一份代码在不同平台编译时只保留对应的分支。

## 六、多端账号互通（绑定原理）

### 6.1 uni-id 的用户数据结构

`uni-id-users` 集合中的一条用户记录可以包含多个第三方 openid：

```json
{
  "_id": "xxx",
  "wx_openid": {
    "mp-weixin": "oP3tG5F..."       // 微信 openid
  },
  "qq_openid": {                     // 绑定后出现
    "mp-qq": "A1B2C3D4E5..."
  },
  "nickname": "快乐大狐狸",
  "avatar_file": { ... }
}
```

当用户从微信登录时，系统查找 `wx_openid.mp-weixin`；从 QQ 登录时，查找 `qq_openid.mp-qq`。如果两个 openid 指向同一条 `uni-id-users` 记录，就是同一个人。

### 6.2 绑定 vs 合并

| 方式 | 描述 | 前提 |
|------|------|------|
| **绑定** | 用户先微信登录，然后主动绑定 QQ | 用户已完成微信登录 |
| **合并** | 两个独立账号需要合并 | 需要共同时（手机号/用户名）或用户手动确认 |

**推荐方案为绑定**，因为用户体验更可控。

### 6.3 绑定流程

```
用户已在微信端登录（有 uid）
    │
    ├─ 点击设置页「绑定QQ」
    │
    ├─ uni.login({ provider: 'qq' })     ← 无感拿 code
    │
    ├─ 调 uniIdCo.bindQQ({ code })
    │     │
    │     ├─ 检查该 QQ openid 是否已被其他账号绑定
    │     ├─ 未被绑定 → 挂到当前账号，返回成功
    │     └─ 已被绑定 → 返回错误（提示用户先解绑）
    │
    └─ 绑定完成，以后从 QQ 进也是同一个人
```

## 七、绑定功能的代码实现

### 7.1 前端绑定按钮

在设置页或账号管理页新增绑定按钮：

```vue
<template>
  <view class="account-bind">
    <view class="bind-item">
      <text>微信</text>
      <text class="bound" v-if="hasWechat">已绑定</text>
      <text class="unbound" v-else>未绑定</text>
    </view>
    <view class="bind-item" @click="bindQQ">
      <text>QQ</text>
      <text class="bound" v-if="hasQQ">已绑定</text>
      <text class="unbound" v-else>未绑定</text>
    </view>
  </view>
</template>
```

### 7.2 绑定方法

```js
async bindQQ() {
    try {
        uni.showLoading({ title: '绑定中...', mask: true })

        // 1. 获取 QQ code
        const loginResult = await uni.login({ provider: 'qq' })
        const loginRes = Array.isArray(loginResult) ? loginResult[1] : loginResult
        if (!loginRes || !loginRes.code) {
            uni.hideLoading()
            uni.showToast({ title: '获取 QQ 信息失败', icon: 'none' })
            return
        }

        // 2. 调用绑定
        const uniIdCo = uniCloud.importObject('uni-id-co', { customUI: true })
        const res = await uniIdCo.bindQQ({ code: loginRes.code })

        uni.hideLoading()
        if (res.errCode === 0) {
            uni.showToast({ title: '绑定成功', icon: 'success' })
            // 刷新用户信息
            mutations.updateUserInfo()
        } else if (res.errCode === 'uni-id-account-exists') {
            uni.showModal({
                content: '该 QQ 已被其他账号绑定，请先解绑',
                showCancel: false
            })
        } else {
            uni.showToast({ title: '绑定失败', icon: 'none' })
        }
    } catch (e) {
        uni.hideLoading()
        console.error('[bindQQ] error:', e)
        uni.showToast({ title: '绑定异常', icon: 'none' })
    }
}
```

### 7.3 检查绑定状态

通过 `uniIdCo.getUserInfo()` 或读取 `store.userInfo`，检查用户的 `qq_openid` 字段是否存在：

```js
computed: {
    hasQQ() { return !!this.userInfo.qq_openid },
    hasWechat() { return !!this.userInfo.wx_openid }
}
```

## 十、注意事项

### 10.1 customUI: true

所有静默操作（loginByWeixin、loginByQQ、bindQQ）的 `importObject` 都要传入 `{ customUI: true }`，防止 uni-id-co 弹出界面。

### 10.2 条件编译

| 平台 | 条件编译 | 对应 login API | 对应 uni-id-co 方法 |
|------|---------|---------------|-------------------|
| 微信小程序 | `#ifdef MP-WEIXIN` | `uni.login({ provider: 'weixin' })` | `loginByWeixin` |
| QQ 小程序 | `#ifdef MP-QQ` | `uni.login({ provider: 'qq' })` | `loginByQQ` |

### 10.3 绑定 vs 重复注册

- **绑定**：同一用户已有账号记录，将第二个平台的 openid 挂到该记录下
- **不绑定的情况**：用户在微信端注册了一个账号、在 QQ 端又注册了一个账号，两个独立

如果未来需要做账号合并，需要实现以下逻辑：
1. 通过手机号/邮箱判断是否同一个人
2. 提供手动合并操作界面
3. 合并时将两个 openid 归到同一条 `uni-id-users` 记录

### 10.4 关于用户头像和昵称

静默注册/登录**拿不到用户头像和昵称**，只能拿到 openid。如需显示头像和昵称，保留手动微信登录按钮供用户主动授权。
