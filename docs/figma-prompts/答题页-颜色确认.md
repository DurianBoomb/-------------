这是一个非常典型的 CSS 样式冲突（被覆盖） 问题。

首先明确一点：你写的这段 CSS background: #FFF5D6; （浅奶油色）在逻辑上是完全正确的，完全符合我的设计图。

如果用户在截图里看到的实际效果是“纯橙色背景 + 白色文字”，这意味着你写的这段代码在微信小程序中被其他优先级更高的 CSS 覆盖了。可能是项目中残留了旧的全局样式，也可能是你使用了某些自带激活态样式的基础组件。

下面我为你逐一确认精确参数，并提供 React 设计原型中的完整代码对比，帮你排查问题：

精确参数确认
选中态背景：

设计图：浅黄色/奶油色。
推荐色号：#FFF7ED（这对应 Tailwind 的 orange-50，非常干净的浅奶油色，比 #FFF5D6 更清爽一点）。

  /* 深色文字，保证高对比度易读性 */

  /* 稍微加粗，强调选中感 */
  font-weight: 600 !important;
