## 搜索页 · 给 Figma AI 的设计提示词

请用 React + Tailwind CSS 为我生成一个移动端搜索页面。这是一个集搜索和分类浏览于一体的页面。

### 页面布局（从上到下）

**1. 顶部搜索框**
- 左侧放大镜图标，占位文字「搜点啥，万一有呢…」
- 右侧「取消」按钮，点击返回首页

**2. 搜索结果区域（固定高度）**
- 无输入时：显示默认文案「输入点什么吧，你不打字我怎么知道你想测啥」
- 有输入时：实时展示搜索结果列表卡片（emoji + 测试标题 + 标签名）
- 区域高度**固定为4条结果的高度，第5条只露出上半截**，引导用户滚动
- 右侧有一个**细小的滑动进度条**，提示用户位置和可滚动
- 结果多时区域内滚动，触底自动加载更多
- 点击任意结果 → 跳答题页

**3. 分类手风琴区域**
- 6个分类，纵向排列：
  - 性格搞怪 🤡 / 趣味整活 🤪 / 逆天知识 👽 / 玄学运势 🔮 / 情感离谱 💔 / 职场发疯 💣
- **第一个分类默认展开**，其余收起
- 每个分类项由两部分组成：
  - 头部：分类名 + 箭头（▾ 展开 / ▸ 收起），点击切换展开/收起
  - 展开内容：该分类下的**标签池**——和首页标签池一样的样式、掉落动画、换一批按钮，但只在该分类范围内刷新

### 交互逻辑
- 搜索时：搜索结果区显示结果列表，分类区域被推到下方（页面整体可滚动）
- 清空搜索框：恢复默认文案，分类区域回到视野中
- 手风琴：一次只能展开一个分类（展开新分类时自动收起上一个）

### 技术要求
- 移动端视口（375px-448px）
- 背景色 #F7F8FA，与首页一致
- 搜索输入有防抖（0.3s）
- 标签池掉落动画与首页保持一致
