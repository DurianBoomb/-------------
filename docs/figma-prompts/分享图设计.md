# 分享图设计需求

## 目标

设计一张微信小程序分享卡片封面图，程序会通过 **Canvas 代码将设计稿逐像素还原**（并非直接使用设计稿图片）。所以设计完成后还有一个 **移植环节**——开发人员根据设计稿上的标注，用 Canvas API 一行一行把图形和文字画出来。

这意味着：
- 设计稿不是"出图就行了"，而是 **移植的施工图纸**
- 每个元素的精确参数都必须标注清楚，否则无法移植
- 设计时需要提前知道：**这个效果 Canvas 能不能画出来？**

---

## 基础信息

| 项目 | 值 | 说明 |
|------|-----|------|
| **用途** | 分享到微信好友/群聊时，卡片上显示的图片 |
| **画布尺寸** | **500 × 400 px** | 推荐 5:4 比例，请按此尺寸出图 |
| **渲染方式** | Canvas 代码还原（非图片资源加载） | 不支持使用外部图片，不支持加载自定义字体文件 |
| **输出平台** | 微信小程序 | |

---

## 移植环节说明（重要）

### 移植流程

```
Figma 设计 → 出标注文档 → 开发人员按标注手写 Canvas 代码 → 运行验证
```

- 设计稿的每一个元素都会被翻译成对应的 Canvas 绘图指令（`fillRect`、`fillText`、`quadraticCurveTo` 等）
- 移植不是切图导出，是**代码还原**
- 标注越精确，还原度越高

### 移植难度分级

| 难度 | 元素类型 | 说明 |
|------|---------|------|
| ★ 简单 | 纯色矩形、圆角矩形、实心圆 | Canvas 原生支持，直接一行代码 |
| ★ 简单 | 文本（PingFang / sans-serif） | `fillText()` 直接渲染，指定字号/颜色即可 |
| ★★ 中等 | 渐变色（线性/径向） | Canvas 支持，需要标注起止色和方向 |
| ★★ 中等 | 图标/Emoji | Emoji 直接用 `fillText()` 渲染；图形图标需转为 Canvas Path |
| ★★★ 困难 | 复杂图形/不规则形状 | 需要手动写 Path 贝塞尔曲线，开发成本高 |
| ★★★ 困难 | 阴影、高斯模糊、投影 | 微信小程序 Canvas 性能有限，低端机可能卡顿 |
| ✗ 不可移植 | 自定义字体（woff/ttf） | 小程序 Canvas 不支持加载外部字体文件 |
| ✗ 不可移植 | 外链图片/网络图 | Canvas 无法跨域加载图片用于绘图 |
| ✗ 不可移植 | 图层混合模式（叠加、正片叠底等） | Canvas 仅支持 `globalCompositeOperation` 有限几种模式 |

### 对设计师的建议

- **优先使用纯色块和文字排版**，移植最准、最快
- **如需图标**，优先选 Emoji 方案（兼容性好、零移植成本）
- **如需渐变色**，标注清楚渐变方向（水平/垂直/角度）和起止颜色
- **如需复杂装饰图形**，提前和开发确认 Canvas 能否实现，避免设计完发现做不了
- **圆角**可以直接用，Canvas 有圆角矩形的绘制方法

## 设计要求

### 必须包含的元素

1. **标签名** — 最大、最醒目的文字，是分享卡的核心内容
2. **问卷标题** — 辅助说明，字号小于标签名
3. **引导文案** — 引导用户点击的短句，位置不限
4. **底部品牌标识** — 如"微信小程序 · xxx"之类

### 可选元素

- 顶部/装饰性色块或渐变条
- 图标/Emoji
- 分隔线
- 背景色块/底纹

### 设计约束

1. **字体**：仅支持系统安全字体（PingFang / Noto Sans SC / sans-serif），不支持上传自定义字体
2. **图标**：支持三种方案——
   - Emoji 字符（用 `fillText()` 渲染，兼容性好）
   - 纯文字排版（无图标）
   - Canvas Path 绘制（复杂图形，开发成本高，慎重选择）
3. **圆角矩形**：Canvas 可以画圆角矩形，见下方标注要求
4. **不要使用阴影/滤镜**：Canvas 渲染性能有限，复杂特效在小程序低端机上可能出现问题

```js
// --- 工具函数 ---
function drawCircle(ctx, cx, cy, r, fill) {
  ctx.fillStyle = fill;
  ctx.beginPath(); ctx.arc(cx, cy, r, 0, Math.PI * 2); ctx.fill();
}
function drawRoundRect(ctx, x, y, w, h, r, fill, opts = {}) {
  ctx.beginPath();
  ctx.moveTo(x + r, y);
  ctx.arcTo(x + w, y, x + w, y + h, r);
  ctx.arcTo(x + w, y + h, x, y + h, r);
  ctx.arcTo(x, y + h, x, y, r);
  ctx.arcTo(x, y, x + w, y, r);
  ctx.closePath();
  ctx.fillStyle = fill; ctx.fill();
  if (opts.stroke) {
    ctx.strokeStyle = opts.stroke;
    ctx.lineWidth = opts.lineWidth || 1;
    ctx.stroke();
  }
}
function drawLine(ctx, x1, y1, x2, y2, color, width) {
  ctx.beginPath(); ctx.moveTo(x1, y1); ctx.lineTo(x2, y2);
  ctx.strokeStyle = color; ctx.lineWidth = width; ctx.stroke();
}
function drawText(ctx, text, x, y, opts) {
  ctx.font = opts.font;
  ctx.fillStyle = opts.color || '#000';
  ctx.textAlign = opts.align || 'left';
  ctx.textBaseline = opts.baseline || 'alphabetic';
  ctx.fillText(text, x, y, opts.maxWidth);
}
```

## 四点五、自适应文本三件套 (必须实现,不可省略)

> **背景**:Canvas 的 `fillText(text, x, y, maxWidth)` 在超宽时会**横向压扁字形**,会让"贱贱的"大字气质瞬间崩坏。
> 因此本卡片**禁止依赖 `maxWidth` 自动压缩**,必须用 `measureText` 主动测量 → 降字号 → 截断的三段式策略。

### A. `fitTagSize` — 大标签名字号二次校验

策略:先按字数选档(52 / 44 / 36),再用 `measureText` 检查实际宽度,若仍超过 `maxWidth` 就继续向下降一档,降到 36 仍超则强制 28px 兜底。**不裁剪**,因为大标签名本身就是主视觉,被截掉一个字会比缩小更难看。

```js
function fitTagSize(ctx, text, maxWidth) {
  // 按字数预估的初始档位
  const tiers = [52, 44, 36, 28];
  let idx = text.length <= 6 ? 0 : text.length <= 9 ? 1 : 2;
  // measureText 二次校验:仍超就继续降档
  while (idx < tiers.length) {
    ctx.font = `900 ${tiers[idx]}px PingFang SC, sans-serif`;
    if (ctx.measureText(text).width <= maxWidth) break;
    idx++;
  }
  return tiers[Math.min(idx, tiers.length - 1)];
}
```

**关键点**:
- `ctx.font` 必须在每次 `measureText` 前**显式赋值**,否则测量的是上一次绘制残留的字体。
- 字重必须保持 `900`,降字号但不降字重,保留视觉冲击力。
- 兜底 28px 是设计师可接受的最小值,再小就破坏"大字标签"心智。

### B. `fitCtaMain` — CTA 主文字号 + 末尾裁剪

策略:先用 20px 测整串 `点击测一测「{TAG}」`,超宽则降到 18px;**18px 仍超就只截 `{TAG}` 末尾加 `…`**,前缀 `点击测一测「` 和后缀 `」` 一个字都不能丢(否则失去引导语义)。

```js
function fitCtaMain(ctx, tag, maxWidth, baseSize, fallbackSize) {
  const prefix = '点击测一测「';
  const suffix = '」';
  const build = (t) => `${prefix}${t}${suffix}`;

  // 第一步:用基础字号 (20px) 测
  ctx.font = `700 ${baseSize}px PingFang SC, sans-serif`;
  if (ctx.measureText(build(tag)).width <= maxWidth) {
    return { text: build(tag), size: baseSize };
  }

  // 第二步:降到 18px 再测
  ctx.font = `700 ${fallbackSize}px PingFang SC, sans-serif`;
  if (ctx.measureText(build(tag)).width <= maxWidth) {
    return { text: build(tag), size: fallbackSize };
  }

  // 第三步:18px 仍超 → 二分截 tag,末尾加 …
  let lo = 1, hi = tag.length, best = 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    const trial = build(tag.slice(0, mid) + '…');
    if (ctx.measureText(trial).width <= maxWidth) { best = mid; lo = mid + 1; }
    else { hi = mid - 1; }
  }
  return { text: build(tag.slice(0, best) + '…'), size: fallbackSize };
}
```

**关键点**:
- 二分查找保留尽可能多的 `{TAG}` 字符,优于线性 `for` 循环。
- 字号降级与截断**只触发一项**,先尝试降字号,降无可降再截字。
- 截断单位是**字符**(`String.prototype.slice`),不要按字节,中文小程序里都是 UTF-16 code unit,直接 slice 即可。

### C. `fitQuiz` — 副标题主动降字号 + 手动截断

策略:与 CTA 同结构,先 18px → 16px,16px 仍超则二分截末尾加 `…`。**禁止传 `maxWidth` 给 `fillText`**(那会让 Canvas 自动横向压扁字形)。

```js
function fitQuiz(ctx, quiz, maxWidth, baseSize, fallbackSize) {
  ctx.font = `400 ${baseSize}px PingFang SC, sans-serif`;
  if (ctx.measureText(quiz).width <= maxWidth) {
    return { text: quiz, size: baseSize };
  }

  ctx.font = `400 ${fallbackSize}px PingFang SC, sans-serif`;
  if (ctx.measureText(quiz).width <= maxWidth) {
    return { text: quiz, size: fallbackSize };
  }

  // 二分截断
  let lo = 1, hi = quiz.length, best = 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (ctx.measureText(quiz.slice(0, mid) + '…').width <= maxWidth) {
      best = mid; lo = mid + 1;
    } else { hi = mid - 1; }
  }
  return { text: quiz.slice(0, best) + '…', size: fallbackSize };
}
```

**关键点**:
- 调用 `drawText` 时**不要传 `maxWidth` 参数**,改为传裁剪后的最终文本。
- 16px 是副标题字号下限,再小阅读会吃力。
- 6-20 字的设计区间下,通常 18px 就能放下;降级与截断是兜底防御。

### D. 共用注意事项

1. **小程序 Canvas 2D 的 `measureText` 只返回 `width`**,不返回 `actualBoundingBoxAscent` 等高度信息,所以行高仍需手动按设计稿固定。
2. **字体未加载完成时,`measureText` 会按系统兜底字体测量**,首次绘制如果遇到此问题,可在 onReady 后延迟一帧再绘制 (`setTimeout(() => draw(), 0)`),保证 PingFang SC 已就位。
3. **DPR 适配**:`measureText` 返回的是 CSS 像素宽度,不需要乘 dpr;但绘制时若用了 `ctx.scale(dpr, dpr)`,字号也按 CSS px 写即可。
4. **测试用例**:每个适配函数都应覆盖 3 字 / 6 字 / 9 字 / 12 字 / 极端长 18 字,确保所有分支都跑过。

## 七、关键移植 checklist

- [ ] CTA 主文:`fitCtaMain` 先降 20→18px,18px 仍超则**二分截 {TAG} 末尾加 `…`**,前后缀不可丢 (见 §四点五·B)
