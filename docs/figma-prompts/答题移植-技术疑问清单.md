## 二、CSS animation 重播（第 5.5 节 · digit-roll）

**你的文档说：**

**实际 Vue 2 + 小程序端：**

## 三、CSS 自定义属性在 @keyframes 中（第 5.7 节 · 背景光斑）

**你的文档用 `var(--dx)`, `var(--dy)` 控制光斑漂移：**
```css
@keyframes orbDrift {
  50% { transform: translate(var(--dx), var(--dy)) scale(1.15); }

```

**实际环境：**
微信小程序的 WXSS 解析器对 `var()` 在 `@keyframes` 内的支持，在 Android 低版本基础库上不可靠。

**问题：** 背景光斑的漂移动画你建议怎么实现？

- B. 改用 JS 驱动 transform（用 `requestAnimationFrame` 更新）
- C. 放弃 WXSS keyframes，改用 uni-app 的 animation API？
- D. 如果兼容目标版本够新，坚持用 `var()` 也可以？

**你的最小支持基础库版本是多少？**

## 八、震动三连可能在 iOS 上被吞（最后一题时序）

最后一题时间线：
