## 首页 v2 · 给 Figma AI 的设计提示词

请用 React + Tailwind CSS 为我生成一个移动端首页。这是一个**互联网娱乐测试小程序**的首页，用户行为模型请参考**抖音/短视频App**——用户没有明确目的，打开就是随便刷刷，看到有意思的就点进去。

### 核心气质
- **贱贱的、好玩**，像个人作品不像大厂产品
- **懒人友好**——用户不需要思考"我要测什么"，页面替他决定
- **用爱发电的手工感**——有趣味、有温度、不油腻
- 文案可以皮，但别用力过猛

### 页面布局（从上到下）

**1. 顶部品牌区**
- 🦊 + 「快乐大狐狸」标题
- 副标题一条欠揍的文案（比如「正经人谁做测试啊…」）
- 右侧一个小圆形头像入口（🥸 或其他）

**2. 搜索栏**
- 圆角搜索框
- 占位文字贱一点（比如「搜点啥，万一有呢…」）

**3. "随便测测"**
- 渐变色卡片（暖色，橙黄系）
- 文案：「随便测测」+ 「瞎选一个，反正测出来也不准」
- 点一下随机跳一个测试

**4. 标签池（核心区域，占最大面积）核心交互 + 动画**
- 不再是分类网格，而是一个**铺满的标签集合**，类似瀑布流或网格排布
- 每个标签是一个圆角 pill 形状（或小卡片），直接显示标签名（如「确诊为烤肠」「搬屎大王」「精神状态良好」）
- 标签量：一次展示 12-20 个
- 右上角或底部有一个**🔄 换一批**按钮

- **🎬 核心动画：标签掉落效果**
  - 页面首次加载或点击"换一批"时，标签从画面**上方不同位置垂直掉落**进池子
  - 每个标签掉落时有**随机延迟**（0-0.5s 随机），形成错落的"下雨"效果
  - 掉落动画使用**弹性缓动曲线**（cubic-bezier），到达终点后轻微弹两下，模拟真实掉落的物理感
  - 标签掉落过程中，下方的标签**不会被先掉下来的压住**——所有标签各自独立掉落，最终停留在各自的网格位置
  - 视觉上像扭蛋机里的小球一个一个掉进槽位

- **动画实现参考**：用 CSS @keyframes + animation-delay 随机值即可，不需要引入物理引擎库。每个标签的动画参数（delay、起始X偏移）在渲染时通过 JS 随机生成并内联到 style 中。

- 标签的视觉呈现可以尝试不规则排布（大小不一？彩色随机？），让它看起来有活力、杂乱但有生机，像一张"标签贴纸墙"
- 点任意标签 → 直接跳答题页

> **设计参考**：可以想象成一个"装满口味的扭蛋机"，或者短视频App的"发现页"——信息量大但不费脑。

**5. 🔥 大家都在搜（可选，视空间决定）**
- 横向滚动的热门标签行
- 标签前带 # 号

**6. ✨ 为你推荐（可选，视空间决定）**
- 2-4 张推荐卡片，带emoji、标题、简介、题数
- 如果空间不够可以只显示前两条，或做成可折叠的

### 技术要求
- 移动端视口（375px-448px 宽度为基准）
- 所有元素可点击，有点击反馈
- 背景色 #F7F8FA，卡片白色
- 整体干净、圆润、不拥挤

---

**最重要的设计挑战**：让"标签池"看起来不像分类列表，而像一个好玩的、让人想点两下的内容广场。请发挥你的创意。
