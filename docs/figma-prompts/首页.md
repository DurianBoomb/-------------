## 首页 · 给 Figma AI 的设计提示词

请用 React + Tailwind CSS 为我生成一个移动端首页。这是一个**互联网娱乐测试小程序**的首页，不是正经应用，请抓住以下气质。

### 核心气质（最重要）

- **贱贱的、有点逆天**——看着不太正经，但又让人想点进去
- **用爱发电的个人作品感**——有温度、有个性、像独立开发者熬夜搞出来的，不像大厂产品
- **千万不能用力过猛**——只在文案上"犯贱"，视觉上干净清爽。整体是"一本正经地胡说八道"的感觉，不是精神污染
- **不要安全方案**——宁愿有一个让人"卧槽"的特点，也不要四平八稳的模板

### 页面功能模块

以下每个模块的具体视觉风格由你自由发挥，我只描述功能：

**1. 顶部品牌区**
- 主标题「快乐大狐狸」——不用特别大特别粗，可以俏皮一点
- 小字说明——描述这个小程序是干嘛的，文案你自己想一个幽默点的（不要"发现更好的自己"这种正经话）
- 可以加一只狐狸元素（文字/emoji/小图标都行，看你）

**2. 搜索入口**
- 搜索框，占位文字你自己想一个皮一点的（比如「搜点啥，万一有呢」这种调调）
- 不用真的实现搜索功能，只是一个入口占位

**3. "随便测测"区域**
- 让用户盲选一个测试，随机出题
- 按钮文案你自由发挥，要符合整体"贱贱的"气质

**4. 分类浏览网格**
- 6个分类，每个显示分类名 + 一个相关emoji：
  - 性格搞怪 / 趣味整活 / 逆天知识 / 玄学运势 / 情感离谱 / 职场发疯
- 每个分类显示"X个测试"

**5. 热门标签滚动**
- 横向滚动的标签列表
- 标签示例：确诊为烤肠、搬屎大王、板砖武器、精神状态良好、摸鱼天花板、抽象大师
- 每个标签点击后跳转到对应答题页

**6. 测试推荐列表**
- 几张测试卡片的推荐列表，每条卡片显示：
  - 左侧emoji
  - 测试标题（离谱一点）
  - 一句话简介（欠揍一点）
  - 底部元信息：「XX题·X分钟」
- 示例卡片标题：你被确诊为什么东西、你的专属武器是什么、搬屎大王等级测试、你的精神状态还好吗

### 技术要求
- 移动端视口（375px 宽度为基准）
- 所有卡片/标签都是可点击的（cursor: pointer 或 hover 效果）
- 干净的交互反馈（点击缩放效果）

---

请发挥你的设计能力，不要套模板，做一个有人格魅力、让人想截图发朋友的首页。
