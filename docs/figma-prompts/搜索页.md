## 搜索页 · 给 Figma AI 的设计提示词

请用 React + Tailwind CSS 为我生成一个移动端搜索页面。这是首页点击搜索框后进入的页面。

### 核心定位
- **只做精确查找和分类浏览**——热搜和推荐在首页已经有了，不重复
- **搜索和分类合在一个页面**，用 Tab 切换

### 页面布局

**1. 顶部搜索框**
- 自动聚焦（页面加载后键盘自动弹出）
- 框内左侧放大镜图标
- 占位文字「搜点啥，万一有呢…」
- 右侧一个「取消」按钮，点击关闭搜索页返回首页

**2. Tab 切换（搜索框下方）**
- 两个 Tab：「搜索」和「分类」
- 选中态有底部横线或高亮

**3. 「搜索」Tab 的内容**
- 输入文字后，下方实时展示匹配的测试结果列表
- 每条结果格式：emoji + 测试标题 + 标签名
- 点击直接跳答题页
- 未输入时显示空白或一句欠揍的提示（比如「输入点什么吧，你不打字我怎么知道你想测啥」）

**4. 「分类」Tab 的内容**
- 6 个分类卡片（2列网格），与首页的分类相同：
  - 性格搞怪 🤡 / 趣味整活 🤪 / 逆天知识 👽 / 玄学运势 🔮 / 情感离谱 💔 / 职场发疯 💣
- 点击分类 → 展示该分类下的所有测试列表
- 测试列表格式与搜索结果的列表一致

### 技术要求
- 移动端视口（375px-448px）
- 背景色 #F7F8FA，与首页一致
- 搜索输入有防抖（打字停 0.3s 后触发搜索）
- 页面切换顺滑（Tab 切换无闪烁，列表过渡自然）

1. **组件结构**：页面的主要组件层级和布局方式
2. **交互逻辑**：搜索防抖的实现方式、Tab 切换的数据处理
3. **数据流转**：搜索结果的数据结构、分类数据如何组织
