## 结果页 · 给 Figma AI 的设计提示词

请用 React + Tailwind CSS 为我生成一个移动端答题结果页。这是用户答完所有题目后看到的最终页面。

### 核心气质
- **惊喜感**——用户答完题等待结果时带着期待，结果要够有冲击力
- **分享欲**——页面设计要让人看了就想截图发朋友/发朋友圈
- **欠揍文案**——结果描述要好笑，不是正经分析
- **与首页和答题页风格一致**

### 页面布局（从上到下）

**1. 顶部结果大标题**
- 大号 emoji（根据结果类型动态变化，例如 🌭 / 🧱 / 💩）
- 结果类型名称，字体大而粗，例如「你被确诊为淀粉肠」
- 一句欠揍的副标题，例如「别挣扎了，你骨子里就是根5块钱的淀粉肠」

**2. 维度得分雷达图**
- 一个简洁的蜘蛛网/雷达图，展示各维度的归一化得分（0-100）
- 不需要太复杂，线条清晰，配色与整体一致即可
- 每个维度顶点显示维度名称

**3. 结果描述区域**
- 一段结果描述文字，讲述这个结果类型的"特征"
- 文案风格：好笑、有梗、适合截图。例如：
  「你的淀粉肠指数高达 92%，加肉程度仅为 8%。你就像那根3块钱的路边摊淀粉肠——看着像肠，其实全是淀粉。优点是便宜实惠不掉价，缺点是……确实没啥营养。」

**4. 操作按钮（底部固定）**
- 两个按钮横向排列：
  - **「分享给朋友」** ——主按钮，显眼
  - **「再来一次」** ——次按钮，重新测一次（回到首页或重新答题）

**5. 底部小字（可选）**
- 「测着玩的，别当真 😅」
- 或者类似免责声明式的欠揍文案

### 数据来源
结果页接收以下数据（通过 URL 参数或状态传递）：
```js
{
  resultType: {
    name: "淀粉肠",
    emoji: "🌭",
    title: "你被确诊为淀粉肠",
    subtitle: "别挣扎了，你骨子里就是根5块钱的淀粉肠",
    desc: "你的淀粉肠指数高达 92%，加肉程度仅为 8%..."
  },
  scores: [92, 8, 75, 30, 60, 45, 80, 20],  // 各维度的归一化得分
  dimensions: ["淀粉肠指数", "加肉程度", "抗造性", "性价比", ...],
  confidence: 0.85  // 匹配置信度
}
```

### 技术要求
- 移动端视口（375px-448px）
- 背景色 #F7F8FA
- 雷达图使用 SVG 或 Canvas 绘制（或简单的 CSS 多边形）
- 页面可滚动（内容可能较长）
- 分享按钮需要明显的点击反馈

### 入场动画
结果页加载时，各元素依次入场，制造"揭晓答案"的仪式感：

1. emoji + 结果名：从上方掉落（同标签池的 elastic 曲线），0.5s
2. 雷达图：从中心向外扩散绘制，0.6s
3. 结果描述：从下方上滑淡入，0.4s
4. 底部按钮：从下方上滑淡入，0.3s
5. 各元素之间间隔 0.15s，形成层次感
