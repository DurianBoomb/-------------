# 页面：照照镜子（用户画像页）

> 给 Figma 设计 / 开发协作用，说明页面结构、功能模块、交互逻辑与设计约束。

---

## 1. 页面入口

通过底部导航栏「**我的**」进入，功能定位为展示用户已诊断/测评过的所有标签结果汇总。

---

## 2. 页面整体布局

从上到下共三个区域，**垂直排列**：

```
┌─────────────────────────────┐
│       顶部导航区             │
│  ←  照照镜子                  │
│  昵称：xxx ✏️                │
│  已确诊 N 个标签              │
├─────────────────────────────┤
│                             │
│     标签列表（滚动区域）       │
│  ┌─── ──────── ───┐         │
│  │  📊 丨 标签名       │         │
│  │     结果名       │         │
│  └─── ──────── ───┘         │
│  ┌─── ──────── ───┐         │
│  │  🔥 丨 标签名       │         │
│  │     结果名       │         │
│  └─── ──────── ───┘         │
│         ...                   │
│                             │
└─────────────────────────────┘
```

## 3. 功能模块详情

### 3.1 顶部导航区（hd）

| 元素 | 说明 | 交互 |
|------|------|------|
| 返回按钮 | 左箭头图标，浅灰圆形背景 | 点击 `uni.navigateBack()` 返回上一页 |
| 页面标题 | 「照照镜子」，加粗大字 | 纯展示 |
| 昵称条 | 「昵称：xxx ✏️」，灰底圆角容器，可点击整条区域 | 点击弹出「修改昵称弹窗」 |
| 副标题 | 「已确诊 N 个标签」，浅色小字 | 纯展示，N 为标签数量 |

#### 修改昵称弹窗（模态）

| 元素 | 说明 |
|------|------|
| 遮罩层 | 半透明黑色，点击遮罩可关闭弹窗 |
| 弹窗主体 | 白色圆角卡片 |
| 标题 | 「修改昵称」，居中 |
| 输入框 | 文本输入，`maxlength=7`，placeholder「最多 7 个汉字」，支持回车确认 |
| 取消按钮 | 灰底灰字，点击关闭弹窗 |
| 保存按钮 | 橙黄渐变底白字，触发保存逻辑 |

保存逻辑：
1. 校验非空 → 提示
2. 本地敏感词校验（`checkSafeWord.verify`）→ 提示
3. 调用云函数 `survey.updateNickname({ nickname })` 
4. 成功 → 更新本地缓存 + Toast「昵称已更新」
5. 失败 → 根据 `errCode` 提示对应错误

---

### 3.2 标签列表区（body）

滚动容器 `scroll-view`，内含三种状态：

#### A. 加载态（`loading === true`）

```
      ⏳
   加载中...
```

- 居中垂直排列
- 图标：⏳
- 文字：「加载中...」

#### B. 空态（`list.length === 0`，加载完成）

```
      📋
  你还没有诊断过任何标签
  去首页随便测测吧 🧐
```

- 居中垂直排列
- 图标：📋
- 主文字：「你还没有诊断过任何标签」
- 副文字：「去首页随便测测吧 🧐」（更小、更浅）

#### C. 列表态（有数据）

垂直排列的卡片列表，每张卡片包含：

```
┌──────────────────────────┐
│ ┌────┐                   │
│ │ 📊 │  标签名           │
│ └────┘  结果名           │
└──────────────────────────┘
```

| 卡片元素 | 说明 |
|----------|------|
| 左侧图标 | emoji 图标，橙黄背景圆角方块容器 |
| 中部信息 | 标签名（加粗大号）+ 结果名（橙色小号） |

卡片交互：
- 整张卡片可点击
- 点击跳转至 `answer-quiz?tag=<encodeURIComponent(item.tagName)>`
- 有 `hover-class="press-98"` 按压缩放反馈

数据来源：云函数 `survey.getUserProfile()`，返回 `{ errCode: 0, data: [{ tagName, resultName, emoji }] }`

## 4. 设计约束

### 技术栈
- uni-app + Vue2（非 Vue3/Composition API）
- 微信小程序环境
- 设计稿基准宽度：**750rpx**

### 必须保留的功能与交互
| 必须保留 | 可重新设计 |
|----------|------------|
| 顶部导航：返回按钮 + 标题 + 副标题 | 字体、间距、背景样式 |
| 昵称展示 + 点击编辑弹窗 | 昵称条的外观、弹窗的视觉风格 |
| 弹窗：输入框 + 取消/保存按钮 | 弹窗形状、颜色、动画 |
| 标签卡片：图标 | tagName | resultName | 卡片质感、圆角、阴影、间距 |
| 卡片点击跳转详情页 | 点击态动效 |
| 三种状态（加载/空/列表） | 状态的视觉表达 |

功能逻辑、数据流、交互反馈（Toast、loading）**不能改变**。

### 颜色体系
- 主色延续暖橙：`#FFB900` → `#FF6900` 渐变
- 现有配色：文字 #101828 / #1E2939 / #6A7282 / #99A1AF，背景 #F7F8FA，卡片白色
- **可以**优化颜色系统——使信息层级更清晰，但保持暖橙基调

---

## 5. 设计方向建议

> 当前状态：功能可用，但视觉上偏"工具感"。希望升级方向：

1. **卡片质感**：用更精致的圆角、阴影、微光效，提升"社交/个人中心"的感觉
2. **信息层级**：标题、昵称、标签名、结果名的大小/粗细/颜色区分更明确
3. **留白与间距**：呼吸感更强，不要挤在一起
4. **状态页面**：加载态和空态不要只是文字，可以用更有设计感的插画/图形表达
5. **动效**：列表项入场动画（如渐入、上滑），弹窗打开/关闭的过渡动画
6. **昵称编辑**：弹窗可以增加微交互动效，如输入框聚焦高亮、按钮反馈
