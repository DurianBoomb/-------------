我在 Vue 2 + uni-app（H5 浏览器调试）中移植了搜索页，出现奇怪的动画问题，急需你的帮助。

## 问题描述

**首次进入页面**：第一个展开的分类里的标签有掉落动画（正确）。

**展开/收起其他分类**：标签也有掉落动画（因为用了 `v-if` 重建 DOM）。

**点击「换一批」按钮**：标签**没有**掉落动画——它们只是瞬间出现在新位置，没有 `0 → translateY(-40px) → translateY(0)` 的过渡过程。

## 当前代码结构

### 模板（关键部分）

```html
<view class="accordion-body" :class="{ 'body-open': cat.expanded }">
    <view v-if="cat.expanded" class="body-inner">
        <view class="tag-pool-header">
            <view class="refresh-btn" @click="refreshCategory(ci)">
                <view>🔄</view>
                <text>换一批</text>
            </view>
        </view>
        <view :key="'grid-' + ci + '-' + cat.refreshId" class="tag-grid">
            <view v-for="(t, ti) in cat.tags" :key="t.name + ti + cat.refreshId" class="tag-wrapper"
                  @click="goQuiz(t.name)">
                <view class="tag-inner" :class="t.cls"
                      :style="{ animationDelay: (0.1 + (ti * 0.08)).toFixed(2) + 's' }">
                    <text>{{ t.name }}</text>
                </view>
            </view>
        </view>
    </view>
</view>
```

### JS 方法

```javascript
refreshCategory(idx) {
    const cat = this.categories[idx]
    if (cat.refreshing) return
    cat.refreshId++          // 改变 key，期望触发重建
    cat.tags.sort(() => Math.random() - 0.5)
}
```

