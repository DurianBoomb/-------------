## 工具集首页 · 给 Figma AI 的设计提示词

请用 React + Tailwind CSS 为我生成一个移动端工具集首页。

### 核心气质
- **一本正经的外表**——干净、整洁、像正经产品
- **皮下藏着一丝抽象**——文案、细节里透一点幽默感，但不张扬
- **轻松、透气**——不拥挤，呼吸感强，像是一个人的独立作品而不是大厂产品

### 页面布局

**1. 顶部品牌区**
- 🦊 + 「快乐大狐狸」标题
- 副标题克制一点，不要用力搞笑（比如「一个小工具箱」或「摆弄点小玩意」）
- 右侧个人头像入口 🥸

**2. 工具卡片网格（2列）**
- 每张卡片：大号 emoji（居中） + 工具名 + 一句简短描述
- 目前只有一张卡片：
  - 📝 趣味测试 / 「测着玩的，别当真」
  - 背景色暖橙色系（#FFF7ED）
- 卡片风格干净、圆角、有柔和阴影
- **未来还可以继续加卡片**，请保持网格布局的可扩展性
- 描述的文字不那么正经，但写在卡片上又不觉得违和

**3. 底部留白即可**

### 动画要求（重点）
- **卡片入场动画**：页面加载时，工具卡片从底部依次弹性上滑，像小方块一个一个弹进画面。每张卡片之间间隔 0.1s 的延迟，形成层次感
- **点击卡片**：点击时卡片有**果冻按压反馈**（轻微缩小 + 弹回），松手后感觉有弹性
- **品牌区点缀**：🦊 图标可以有一个**非常轻微**的呼吸浮动（不打扰，但看起来有生气）
- **滚动时**：整个页面滚动顺滑
- 所有动画用纯 CSS @keyframes 实现，不需要引入外部库

### 技术要求
- 移动端视口（375px-448px）
- 背景色 #F7F8FA，与之前的页面一致
- 有点击反馈

### 开发移植说明
请在你的代码输出中附带以下便于移植的说明：
1. **组件结构**：页面的主要组件层级（品牌区 → 卡片网格）
2. **布局方式**：卡片网格的实现方式（grid / flex），为什么这么选
3. **可扩展性**：未来新增卡片时，需要修改哪些地方
4. **跨框架建议**：如果我要在 Vue 2 中实现这个页面，有什么需要注意的关键点

---

**设计参考**：有点像 iOS 的快捷指令 App 那种「工具卡片墙」——每张卡片是一个独立小工具，一目了然。
