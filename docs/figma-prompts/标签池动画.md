## 修改要求

### 标签池的新交互：掉落动画
- 当前标签池是一组静态标签，现在改成：首次加载或点击"换一批"时，标签从画面上方**垂直掉落**进池子
- 每个标签掉落的**起始延迟随机**（0-0.5s），形成错落的"下雨"效果
- 掉落动画使用**弹性缓动曲线**（cubic-bezier），到达终点后轻微弹两下
- 所有标签各自独立掉落，最终停在各自的网格位置

### 实现方式
- 纯 CSS @keyframes + animation-delay 随机值即可，不需要引入外部库
- 每个标签的 animation-delay 和起始水平偏移在渲染时用 JS 随机生成

### 其他设计不变
- 标签仍然是圆角 pill 形状，显示标签名
- 12-20 个标签，网格排布
- 有点击反馈，点击跳转答题页
- 颜色、字体、间距等视觉风格与当前设计保持一致
