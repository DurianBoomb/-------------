## figma回复
在这个充满“快乐、贱贱的、好玩”气质的工具集中，“换一批”按钮的交互反馈是非常关键的情绪释放点。

在 Figma 的设计中，我们并没有使用呆板的匀速旋转，而是继续贯彻了“果冻弹性”的设计语言。以下是原型的动画设计拆解，以及在 Vue 2 + uni-app 中最稳妥的移植方案。

1. Figma 原型中的动画设计拆解
🔄 图标（Icon）的动作：

旋转方向：顺时针旋转一圈（360度）。
单次时长（Duration）：0.5s。
缓动曲线（Easing）：cubic-bezier(0.34, 1.25, 0.64, 1)（与之前调优后的选项入场曲线保持一致）。这会让图标在旋转结束时，有一种“微微转过头又迅速弹回来”的清脆感，非常符合“快乐大狐狸”的调性。
🔘 按钮整体（Button）的动作：

仍然沿用全局的果冻按压（Jelly Press）反馈。
按下时瞬间缩小到 scale(0.96)，松手回弹。
2. 移植到 uni-app 的核心技巧（千万别用 @keyframes）
技术避坑：很多新手做“点击旋转”，会写一个带 @keyframes 的 .spin 类名，点击时加上，转完再用 JS 移除。但这在 Vue/小程序中有个致命缺陷——如果用户连续点击，类名的移除和添加会被 Vue 的异步更新合并，导致动画不触发；或者在移除的瞬间，图标会生硬地“闪现”回 0 度。

最佳实践：使用 Vue 的动态 style 绑定，每次点击让旋转角度累加 360 度。配合 CSS transition，它会顺着当前位置一直平滑地转下去！

3. 完整的 Vue 2 + uni-app 代码
请直接使用以下代码结构，它完美分离了“按钮缩放”和“图标旋转”的 DOM 层级，彻底避免了 transform 冲突。

模板 (Template):

<template>
  <!-- 外层只负责整体的物理按压反馈 -->
  <view class="refresh-btn-wrap" 
        hover-class="press-jelly" 
        :hover-start-time="0" 
        :hover-stay-time="150"
        @click="handleRefresh">
    
    <!-- 内层布局 -->
    <view class="refresh-content">
      <!-- 独立控制图标的旋转 -->
      <view class="icon-wrapper" :style="{ transform: 'rotate(' + spinDeg + 'deg)' }">
        <!-- 这里放你的图标，比如 uni-icons、图片 或 自定义字体 -->
        <image src="/static/icon-refresh.png" class="icon-img"></image>
      </view>
      <text class="btn-text">换一批</text>
    </view>
  </view>
</template>
逻辑 (Script):

export default {
  data() {
    return {
      spinDeg: 0,         // 记录图标当前的累加旋转角度
      isRefreshing: false // 防连点节流锁
    }
  },
  methods: {
    handleRefresh() {
      // 1. 防止疯狂连点导致接口崩溃或动画鬼畜
      if (this.isRefreshing) return;
      this.isRefreshing = true;

      // 2. 核心：每次点击，角度累加 360 度。绝对不要归零！
      this.spinDeg += 360; 

      // 3. 触发你的业务逻辑 (比如重新请求标签池数据)
      this.$emit('refresh');

      // 4. 等待动画播放完毕后（0.5s），解锁
      setTimeout(() => {
        this.isRefreshing = false;
      }, 500);
    }
  }
}

4. 细节注意与验收标准
中心点必须正（Transform Origin）：在 UI 切图或者使用 iconfont 时，务必确保你的“🔄”图标是绝对的正方形，且视觉重心在正中心。如果图标边缘有留白不均匀，旋转时就会像偏心轮一样“瘸腿摇晃”。
防暴击处理：我在代码里加了 isRefreshing 节流锁，必须有这个锁。不仅是为了防止用户狂点导致你的 uniCloud 云函数计费暴涨，也是为了保证旋转动画每次都能从容、优雅地播放完一个周期。
不要轻易改成无限旋转：如果你在请求接口时想让它一直转（animation: spin infinite linear），不仅会破坏我们设计的“清脆感”，还需要在 JS 中动态切换类名，逻辑会变得复杂。对于这种轻量级的测试应用，“点一次，干脆利落地转一圈”是最高级的体验。
