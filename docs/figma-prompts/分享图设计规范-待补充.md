## 六、动态文字的自适应规则 (重点!)

这是设计稿里**唯一需要程序判断**的部分,请严格按以下三套规则实现。设计师已经实测过 3 / 6 / 9 / 12 / 18 字各种长度,字号和裁剪策略都经过审美校准。

### 规则 A:大标签 `{TAG}` (T4 位)

| 字数 | 初始字号 | 备注 |
|------|---------|------|
| 3-6 字 | 52px | 主视觉档,最有冲击力 |
| 7-9 字 | 44px | 次档 |
| 10-12 字 | 36px | 紧凑档 |
| 超长兜底 | 28px | 仅在 measureText 二次校验仍超过 420px 时启用 |

**实现策略**:
1. 按字数选档
2. `ctx.measureText` 测真实宽度
3. 若宽度 > 420px,**降一档继续测**,最终降到 28px 强制兜底
4. **绝不裁剪 `{TAG}`**——它是 C 位,被截掉会比缩小更难看

### 规则 B:副标题 `{QUIZ}` (T5 位)

| 阶段 | 字号 | 触发条件 |
|------|------|---------|
| 默认 | 18px | 6-20 字范围下大部分情况 |
| 降一档 | 16px | 18px 时 measureText > 420px |
| 末尾省略 | 16px + `…` | 16px 仍超 → 二分截断末尾加 `…` |

**实现策略**:
- **绝不传 `maxWidth` 给 `fillText`**——Canvas 的 maxWidth 会横向压扁字形,让文字变细变丑
- 必须主动 measureText → 降字号 → 截字符 三段式

### 规则 C:CTA 主文 `点击测一测「{TAG}」` (T7 位)

| 阶段 | 字号 | 触发条件 |
|------|------|---------|
| 默认 | 20px | 整串 measureText ≤ 320px |
| 降一档 | 18px | 20px 整串 > 320px |
| 末尾省略 | 18px + `…` | 18px 仍超 → **只截 `{TAG}`** 末尾加 `…`,前缀 `点击测一测「` 和后缀 `」` 一个字都不能丢 |

**实现策略**:
- 前后缀的语义"点击测一测「」"必须完整,否则失去引导力
- 用二分查找保留尽可能多的 `{TAG}` 字符

> 💡 三套规则的完整 JavaScript 实现见 [`分享卡-Canvas移植施工图.md`](./分享卡-Canvas移植施工图.md) §四点五

## 十、移植注意事项 (设计师的"踩坑预警")

### 🔥 高优先级 (不照做必踩坑)

1. **小程序 Canvas 圆角矩形要用 `arcTo` 实现**,不要用 `roundRect`——后者在基础库 2.x 早期版本支持不全。
2. **所有文字必须显式设置 `textBaseline`**,默认 `alphabetic` 和我标的 `top` / `middle` 差异非常大,会让排版整体下移 5-8px。
3. **CTA 是水平渐变,背景是垂直渐变**,代码里两个 `createLinearGradient` 的起止点参数不要复制粘贴搞错。
4. **大色斑的圆心 (520,-40) 和 (-30,420) 是故意出界的**,不要"修正"到画布内,溢出感是设计意图。
5. **字体在首次绘制时可能未加载完成**,导致 `measureText` 返回的是系统兜底字体宽度。建议在 `onReady` 后 `setTimeout(draw, 0)` 延迟一帧绘制。
6. **大标签自适应必须二次 measureText 校验**,不能只按字数选档——同样是 6 个字,"我" vs "麼"的实际宽度差异可达 30%。
7. **CTA 主文的「」必须保留**,这是中文方头括号 U+300C / U+300D,不是英文 `[]`。

### 🟡 中优先级 (影响精致度)

8. **DPR 适配**:小程序 Canvas 需要 `const dpr = wx.getSystemInfoSync().pixelRatio; canvas.width = 500 * dpr; canvas.height = 400 * dpr; ctx.scale(dpr, dpr);` 否则导出图会模糊。
9. **菱形旋转必须 `save/restore` 保护上下文**,否则后续元素全部跟着旋转 45°。
10. **emoji 字号设置时不要带 PingFang 字体声明**——系统会优先用 emoji 字体渲染,但部分 Android 设备会因为字体声明导致 emoji 变成黑白文字。建议 `font: '28px sans-serif'` 即可。

### 🟢 低优先级 (锦上添花)

11. **不需要遮罩、混合模式、滤镜**,所有元素都是普通 `fill` / `stroke`。
12. **不需要分层渲染**,所有元素一次性画到同一个 Canvas 即可,无动画无重绘。
13. **可以考虑加 1px 的微弱阴影**到 CTA 渐变长条 (`shadowColor: 'rgba(234,88,12,0.25)', shadowBlur: 8, shadowOffsetY: 4`),但这是可选项,不做也不影响主观感受。

### 🔵 极端边界情况

14. **最长情况测试用例**:`{TAG}` = "我超长的十二字标签名" (12 字) + `{QUIZ}` = "你被确诊为什么类型的不正经选手呢" (16 字),这是设计上限,务必跑通。
15. **最短情况测试用例**:`{TAG}` = "烤肠" (2 字,虽然规定 3-12,但保护性兼容) + `{QUIZ}` = "你是啥" (3 字),此时排版仍要好看,小眉签不能盖到大标签。
16. **空值兜底**:如果 `{TAG}` 或 `{QUIZ}` 为空,要么显示占位文案 "测一测",要么直接不绘制 T4/T5——具体策略由产品决定,**但不能让 Canvas 抛错**。
