## Figma 答题页动画参数确认
在前端动效落地时，“参数正确”和“视觉感受正确”往往是两回事。特别是从 Web (React) 迁移到手机端（微信小程序）时，由于屏幕物理尺寸、设备刷新率和渲染引擎的差异，经常需要对理论参数进行“感官微调”。

针对你用户的反馈，我们逐一调整参数，找回那种“轻快、Q弹、干净”的独立产品气质。

1. cubic-bezier 曲线：需要微调
你目前使用的 cubic-bezier(0.34, 1.56, 0.64, 1) 是一个拥有极大回弹过冲（Overshoot）的曲线。在 Web 端大屏幕上可能看起来像果冻，但在手机端有限的视口内，回弹幅度过大会显得有些“抽搐”或者“用力过猛”，这就是用户觉得弹性不对的原因。

调整建议：收敛回弹幅度，让它更紧凑。
推荐曲线：cubic-bezier(0.175, 0.885, 0.32, 1.275)（这是经典的 easeOutBack，弹性自然且不过分）或者更定制一点的 cubic-bezier(0.34, 1.25, 0.64, 1)（降低了第二个参数 Y 轴的峰值，回弹更克制）。
2. translateY 位移：视觉距离过长
数学换算：你的换算 40px = 80rpx，30px = 60rpx 在数学上是绝对正确的（基于 750rpx 规范）。
感官微调：在手机上，位移距离越长，相同时间内的运动速度就越快。80rpx 在很多大屏手机上是一段不小的物理距离，会导致元素像“射”出来的一样，而不是“浮”出来。
调整建议：将入场距离缩短，离场距离也缩短。
入场 translateY：改为 40rpx 或 60rpx。（不需要死守数学换算，微小位移+透明度变化才是高级感的来源）。
离场 translateY：改为 -40rpx。
3. 动画时长：速度感的刻画
设计意图：这个产品的设计气质应该是“轻盈、丝滑、不拖泥带水”。
当前问题：入场 0.6s 配合 80rpx 的长距离，容易显得前段太急、后段拖沓。离场 0.3s 稍微有一点点慢，会影响用户刷题的连贯快感。
调整建议：
入场（slideUpElastic）：缩短至 0.45s 或 0.5s。
离场（fadeOutUp）：缩短至 0.2s 或 0.25s（离场要极其干脆，“刷”地一下就走）。
选中态保持时间：400ms 是对的，刚刚好。
4. 选项的入场行为：原地浮现即可
解答：不需要改成从屏幕最底部进入视野！
设计本意：选项的入场就应该是“在它原本该待的位置的下方一点点（40rpx）开始，伴随透明度浮现并弹回原位”。这是一种局部的“发牌”感。如果从屏幕最底下飞上来，视觉焦点会被极度拉长，不仅显得乱，而且特别刺眼。
结论：你用 :key 重建 DOM，让它在原位附近触发局部位移，这个做法是完全正确的。
5. 选中态的色彩调优（解决“发灰”问题）
#FFEDD4 发灰是因为它在手机高色域屏幕上饱和度不足，且缺乏对比度。既然我们产品带有“贱贱的”、“好玩”的气质，色彩应该明亮、高对比、干净。

下面是强烈建议的 React 原型同款色值：

未选中状态：

背景色：#FFFFFF（纯白，保持呼吸感）
边框：2px solid #EBECEF（极浅的冷灰色，比纯灰有质感）
文字颜色：#333333（深灰，接近黑，易读）
选中状态（阳光鲜明的主题）：

背景色：#FFF5D6（更明亮、饱和度更高的浅黄）
边框：2px solid #FFB000（高饱和度的纯正橙黄，通过边框的强对比去掉背景的灰败感）
文字颜色：#D97706（加深的品牌橙，或者直接变成 纯黑 #000000 结合加粗 font-weight: bold，冲击力最强）。
🚀 优化后的参考 CSS 代码（直接拿去替换）：
/* 1. 选项入场动画（更紧凑的弹性、更短的距离、更快的速度） */
.option-enter {
  animation: slideUpElastic 0.45s cubic-bezier(0.34, 1.25, 0.64, 1) both;
}

@keyframes slideUpElastic {
  0% { 
    opacity: 0; 
    transform: translateY(50rpx); /* 距离缩短，避免运动过快 */
  }
  100% { 
    opacity: 1; 
    transform: translateY(0); 
  }
}

/* 2. 旧题离场动画（更干脆） */
.question-leave {
  animation: fadeOutUp 0.2s ease-in both;
}

@keyframes fadeOutUp {
  0% { opacity: 1; transform: translateY(0); }
  100% { opacity: 0; transform: translateY(-40rpx); }
}

/* 3. 选项 UI 样式 */
.option-inner {
  background-color: #FFFFFF;
  border: 4rpx solid #EBECEF; /* 2px = 4rpx */
  color: #333333;
  transition: all 0.2s ease; /* 颜色和边框平滑过渡 */
}

/* 选中态 */
.option-inner.is-selected {
  background-color: #FFF5D6;
  border-color: #FFB000;
  color: #000000;
  font-weight: bold;
}

/* 4. 果冻按压反馈（绑定在最外层的 hover-class） */
.press-jelly {
  transform: scale(0.96); /* 没必要0.9，0.96在手机上物理反馈刚好 */
  transition: transform 0.05s ease-in;
}
