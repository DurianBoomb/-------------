# 问题：uniapp 微信小程序手风琴标签池换一批按钮，CSS 掉落动画仅首次生效

## 环境

- Vue 2 + uni-app + 微信小程序
- 页面路径：`pages-tools/search/search-page.vue`

## 需求

手风琴组件展开后，显示 16 个标签的网格。标签入场时有掉落弹性动画（`dropElastic`——`translateY(-80rpx) → translateY(0)`，`opacity: 0 → 1`）。每个标签的 `animation-delay` 不同，形成交错掉落效果。

点击分类右上角的「换一换」按钮，重新洗牌取 16 个新标签，并且**新标签应从头播放掉落动画**。

## 当前效果

- 第一次展开手风琴：动画正常 ✅
- 点击「换一换」：标签内容变了，但没有动画，直接显示 ❌
- 再次点击「换一换」：同样没有动画 ❌

## 关键代码结构

**模板（简化）：**
```html
<view v-if="cat.expanded" class="body-inner">
  <view :key="'grid-' + cat.refreshId" class="tag-grid">
    <view v-for="(t, ti) in cat.tags" :key="ti" class="tag-wrapper">
      <view :class="'tag-inner ' + t.cls" :style="t.animStyle">
        <text>{{ t.name }}</text>
      </view>
    </view>
  </view>
</view>
```

**CSS 动画定义：**
```css
.tag-inner {
  border-radius: 40rpx;
  box-shadow: 0 1rpx 2rpx -1rpx rgba(0,0,0,0.1);
  animation-name: dropElastic;
  animation-duration: 0.6s;
  animation-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1);
  animation-fill-mode: both;
}

@keyframes dropElastic {
  0% { opacity: 0; transform: translateY(-80rpx); }
  100% { opacity: 1; transform: translateY(0); }
}
```

**JS 方法：**
```javascript
refreshCategory(idx) {
  const cat = this.categories[idx]
  if (cat.refreshing) return
  cat.refreshing = true
  cat.spinDeg += 360
  cat.refreshId++
  // 从全部标签中 Fisher-Yates 洗牌取 16 个
  const arr = [...cat._allTags]
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]]
  }
  cat.tags = arr.slice(0, 16).map((t, i) => ({
    ...t,
    animStyle: this.buildAnimStyle(i, cat.refreshId)
  }))
  this.$nextTick(() => {
    cat.refreshing = false
  })
},

buildAnimStyle(idx, refreshId) {
  const delay = (0.1 + Math.abs(Math.sin(idx + refreshId * 10)) * 0.4).toFixed(2)
  return `animation-delay: ${delay}s`
},
```

## 已尝试过的方案及结果

| 方案 | 做法 | 结果 |
|------|------|------|
| 方案 A：`animation: none !important` 复位 | 先将所有标签 inline style 设为 `animation: none !important`，nextTick 后再设为 `animation-delay: Xs`。期望通过样式变更触发动画重播 | 无效。因为 inline style 只控制 delay，`animation-name` 在 CSS 里。元素已存在时改 delay 不会重启动画 |
| 方案 B：`:key` 驱动 DOM 重建 | `:key="'grid-' + cat.refreshId"`，每次换一批时 `cat.refreshId++`，期望 Vue 销毁旧 grid 重建新 grid，新 DOM 节点的 CSS 动画自动触发 | 无效。疑似 uni-app 输出微信小程序时，非 `v-for` 元素的 `:key` 变化不会真实销毁重建 DOM，可能只是重新渲染 |
| 方案 C：方案 A 基础上移除 `animReset` + 仅用 `:key` | 不再设 `animation: none`，只靠 `:key` 变化驱动 DOM 重建，让新节点的 CSS 动画自然触发 | 无效，同方案 B |

## 已确认排除的问题

- ✅ CSS `@keyframes` 定义正确，首次展开时动画正常
- ✅ 标签数据确实变了（内容不同，说明洗牌生效）
- ✅ 新版标签的 `animation-delay` 确实不同
- ✅ 修改代码后已删除 `unpackage` 缓存并重跑，排除模拟器缓存问题
- ✅ `.tag-inner` 的 `animation-name`、`animation-duration` 等属性均在 CSS 文件中定义，未写在 inline style 里

## 核心症结

微信小程序环境中，如何让**已存在于 DOM 中的元素重新触发 CSS animation**？目前已知以下可能路径：

1. **彻底销毁 DOM 节点再重建**（`v-if` 从 `false → true`）——但 `:key` 预期应该做这件事却失败了
2. **动态更换 `animation-name`**——每次刷新生成不同的 keyframe name 并在运行时注入新的 `@keyframes` 规则
3. **用 JS 重触发动画**——如 `element.classList.remove/add` 或 `element.style.animation = ''` 再重置，或调用 `element.reflow()` 强制回流——但小程序环境无完整 DOM API
4. **全 inline animation**——不在 CSS 中定义 `animation-name`，把整个 `animation` 简写属性写在 inline style 里，刷新时通过改变 `animation-name` 的一部分来触发
5. **两层嵌套 + v-if 拔除**——在 `.tag-inner` 外面包一层容器，用 `v-if` 控制这个容器隐藏/显示

# 回复
在 uni-app 编译为微信小程序后，`:key` 并不总会导致 DOM 节点被完全销毁并重建（尤其对非 `v-for` 的元素）。当同一位置的节点被复用时，CSS 动画不会因为属性变化而重新播放。所以方案 B、C 都会失效。而小程序环境又没有完整的 DOM API，无法用 classList 移除再添加的方式重触发动画（方案 A、3 同样无效）。动态注入 `@keyframes` 在小程序里也不可行（方案 2、4）。

**真正可靠的方法**：让节点“彻底离开屏幕再回来”——也就是用 `v-if` 临时卸载整个网格容器，更新数据后再重新挂载。这样 Vue/小程序会创建全新 DOM，CSS 动画自然从头播放。

下面给出完整实现。

## 1. 模板修改

用一个布尔值（如 `cat.gridVisible`）控制网格的 `v-if`：

```html
<view v-if="cat.expanded && cat.gridVisible" class="body-inner">
  <!-- 这里不再依赖 refreshId 做 key，因为 v-if 已经保证重建 -->
  <view class="tag-grid">
    <view v-for="(t, ti) in cat.tags" :key="ti" class="tag-wrapper">
      <view :class="'tag-inner ' + t.cls" :style="t.animStyle">
        <text>{{ t.name }}</text>
      </view>
    </view>
  </view>
</view>
```

## 2. 数据初始化

在 `categories` 的每个分类对象里，增加 `gridVisible: false`，初始不显示（展开时才变为 `true`，这样首次展开也会触发动画）：

```javascript
// 构造 categories 示例
this.categories = rawCategories.map(cat => ({
  ...cat,
  expanded: false,
  gridVisible: false,   // 新增
  refreshId: 0,
  spinDeg: 0,
  refreshing: false,
  _allTags: [...],      // 全部标签池
  tags: []
}))
```

展开分类时记得打开 `gridVisible`：

```javascript
toggleCategory(idx) {
  const cat = this.categories[idx]
  cat.expanded = !cat.expanded
  if (cat.expanded) {
    cat.gridVisible = true
    // 首次展开时填充标签（若尚未填充）
    if (!cat.tags.length) {
      this.refreshCategoryTags(cat)
    }
  } else {
    cat.gridVisible = false
  }
}
```

## 3. 换一批方法

点击「换一换」时，先关闭 `gridVisible`，更新数据，再在 `$nextTick` 里打开，强制重建：

```javascript
refreshCategory(idx) {
  const cat = this.categories[idx]
  if (cat.refreshing) return

  cat.refreshing = true
  cat.spinDeg += 360
  cat.refreshId++

  // 1️⃣ 先隐藏网格
  cat.gridVisible = false

  // 2️⃣ 准备新标签数据（洗牌 + 取 16 个）
  const arr = [...cat._allTags]
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]]
  }
  const newTags = arr.slice(0, 16).map((t, i) => ({
    ...t,
    animStyle: this.buildAnimStyle(i, cat.refreshId)
  }))

  // 3️⃣ 更新数据
  cat.tags = newTags

  // 4️⃣ 重新显示网格（DOM 重建，动画从头播放）
  this.$nextTick(() => {
    cat.gridVisible = true
    this.$nextTick(() => {
      cat.refreshing = false
    })
  })
},

buildAnimStyle(idx, refreshId) {
  const delay = (0.1 + Math.abs(Math.sin(idx + refreshId * 10)) * 0.4).toFixed(2)
  return `animation-delay: ${delay}s`
}
```

> **注意**：`gridVisible` 设为 `false` 后，`v-if` 会在当前渲染周期移除节点；`$nextTick` 后再设为 `true`，下一周期创建新节点。中间只有极短的隐藏间隔，肉眼基本无感。如果仍有闪烁感，可让网格配合 `opacity` 过渡，但通常不需要。

## 总结

核心就一句话：**通过 `v-if` 临时卸载再挂载，强制小程序创建全新节点，使 CSS 动画自然重播**。这是 uni-app 微信小程序下最稳定、最简单的实现方式，无需依赖任何 hack 或 DOM API。
