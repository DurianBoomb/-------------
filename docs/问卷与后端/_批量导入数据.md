# 批量导入操作方法

## 方法：用云函数导入

### 第一步：创建临时导入云函数

1. 在 HBuilderX 中，右键 `uniCloud-alipay/cloudfunctions/` → 新建云函数 → 取名 `import-data`
2. 把以下代码粘贴到 `index.obj.js`：

```javascript
const db = uniCloud.database()

// 标签数据（从 survey-tags.init_data.json 复制过来，只保留 category, name, emoji, description）
const tags = [] // ← 把 survey-tags.init_data.json 全部内容复制到这里替换 []

// 问卷数据（从 surveys_batch_01_50.json 复制过来）
const surveys = [] // ← 把第 1 批问卷复制到这里替换 []

module.exports = {
  _before() {},
  async run() {
    // 插入标签
    let tagOk = 0, tagFail = 0
    for (const t of tags) {
      try {
        await db.collection('survey-tags').add({
          name: t.name,
          category: t.category || '',
          emoji: t.emoji || '',
          description: t.description || '',
          popularity: 0,
          status: 'published',
          surveyCount: 1
        })
        tagOk++
      } catch(e) { tagFail++; console.error(e) }
    }
    
    // 插入问卷
    let svyOk = 0, svyFail = 0
    for (const s of surveys) {
      try {
        await db.collection('surveys').add({
          tagName: s.tagName || s.tag,
          title: s.title || '',
          dims: s.dims || [],
          qs: s.qs || [],
          resultTypes: s.resultTypes || [],
          status: 'active'
        })
        svyOk++
      } catch(e) { svyFail++; console.error(e) }
    }
    
    return { tagOk, tagFail, svyOk, svyFail }
  }
}
```

### 第二步：部署并执行

1. 右键 `import-data` → 上传部署（选阿里云）
2. 在 HBuilderX 底部「uniCloud」面板 → 「云函数运行测试」
3. 选择 `import-data` 云函数 → 调用 `run` 方法

### 第三步：删除临时云函数

数据导入完后，把 `import-data` 云函数文件夹删除。
