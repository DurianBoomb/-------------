严格按照 Figma 回复中给出的全部参数和代码，重写 answer-quiz.vue 的答题过渡动画。

核心改动：

1. 模板结构 — 单 `:key` 重建 → 双槽位（A/B slot）并存模型，`.card position: absolute` 叠在同一坑位实现 120ms 叠加窗口
2. data — 平铺字段改为 `slots` 对象（A/B 槽各维护 visible/phase/q/sel/confirm）+ activeSlot 切换
3. pick() 时序 — 420ms 选中保持 → 旧槽位 phase=out → 100ms 后新槽位插入入场 → 再过 220ms 销毁旧槽位解锁
4. CSS 全部替换 — 4 组新 keyframes（qIn/qOut/oIn/oOut）+ confirmPop，去掉所有 !important，CSS 变量 --idx 实现阶梯延迟
5. 交互参数对齐 — 按压缩放 scale(0.95)、回弹 0.18s、选中确认弹跳 0.22s、文字不加粗到 bold

## 架构设计

**双槽位叠加切换模型**：

- 父容器 `.stage` 设 `position: relative`，每个 `.card` 设 `position: absolute; inset: 0;`
- 每次切题，旧槽位 phase='out' 触发离场，100ms 后新槽位 visible=true/phase='in' 触发入场
- 220ms 后旧 DOM 离场播完，销毁旧槽位

**时序链条**：

```
选中选项
  ├─ 立即：cur.sel=i, cur.confirm=i (触发 confirmPop)
  ├─ 240ms: cur.confirm=-1 (清除类)
  └─ 420ms: cur.phase='out' (离场)
       └─ 100ms: next visible+phase='in' (入场，叠加)
            └─ 220ms: cur.visible=false, locked=false
```

**数据流**：`slots` 对象（A/B）各自维护独立状态，`ans` 数组保持在页面级不受槽位影响，`goResult()` 用 `slots[activeSlot]` 取最后数据。

## 精确参数（逐项对齐 Figma 回复）

| 项 | 精确值 |
| --- | --- |
| 按压缩放 | scale(0.95) |
| 按压塌陷 | 0.05s ease-in |
| 回弹 | 0.18s cubic-bezier(.34, 1.25, .64, 1) |
| 颜色/边框过渡 | 0.18s ease-out |
| 选中文字 | color:#111827; font-weight:500 |
| 选中确认弹跳 | confirmPop 0.22s, scale: 0.95→1.03→1 |
| 选中保持 | 420ms |
| confirmPop 清除 | 240ms |
| 题目离场 | 0.22s, bezier(.4,0,1,1), -32rpx |
| 选项离场 | 0.22s, 同上, -24rpx, delay 0/30/60/90ms |
| 题目入场 | 0.48s, bezier(.34,1.25,.64,1), 40rpx, delay 0.06s |
| 选项入场 | 0.5s, bezier(.34,1.4,.64,1), 48rpx, delay 0.14/0.20/0.26/0.32s |
| 叠加窗口 | 离场后 100ms 插入新题 |


## 注意事项

1. `.qz` 区域原先 `flex:1; display:flex; align-items:center` — 双槽位 `.card absolute` 后脱离文档流，`.stage` 需固定最小高度避免塌陷
2. `goResult()` 从 `slots[activeSlot]` 取最后一题数据，`ans` 数组保持页面级
3. `curQ` 计算属性不再使用
4. 去掉所有 `!important`，用类名隔离替代
