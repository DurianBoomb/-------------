## 产品概述

对全部约357份问卷标签进行稀有度评价，按照五维度评分体系（A意外指数/B解码愉悦度/C共鸣锐度/D延展自洽性/E传播势能）逐份打分，最终产出稀有度分级与CSV总表。

## 核心功能

1. 提取全量357份问卷的结构化数据（tag/title/dims/resultTypes）
2. 基于四份创作理论逐份手动评价：

- 实体隐喻标签：关注单源一致性、特征表可溯源性、品类下位约束（是否贴皮）
- 非实体标签：关注共鸣锐度和传播势能、自然感（粗糙真实优先/画面先行）

3. 文件记录替代记忆，分批次处理确保评分尺度一致
4. 按金字塔定档（Legendary ≤10% / Rare ~20% / Common ~70%）
5. 输出CSV总表与完整评价报告
6. Legendary层做tiebreaker（同分决胜：B+E分值优先）

## 执行策略

### 核心策略：文件记录替代上下文记忆

AI上下文记忆在长任务中会逐步漂移，采用"文件即记录"策略——每次打分结果实时写入本地JSON文件，每批开始时读取历史数据做评分标尺校准。

### 数据提取

- 用Node.js脚本从 `docs/问卷与后端/coze输出二期/全部问卷_合并.json` 提取每份问卷的：tag、title、dims、resultTypes、维度数量、结果数量
- 自动判断实体隐喻型/非实体型标签
- 输出为紧凑JSON文件 `docs/问卷稀有度评价/surveys_data.json`
- 创建空结果文件 `docs/问卷稀有度评价/results.json` 用于逐批追加

### 分批次手动评价

全量357份分为约10批（每批35-40份），每批执行：

1. 读取上一批已评分数据，提取最高分/中位分/最低分3个锚点做标尺校准
2. 逐份阅读tag + dims + resultNames，按A/B/C/D/E逐维度打分
3. 对实体隐喻标签特别关注：dim是否从实体属性自然长出、result是否为真实品类而非贴皮
4. 对非实体标签特别关注：共鸣是否精准、传播势能是否强、语言是否自然（粗糙真实优先）
5. 通过JSON追加写入方式将本批评分合并到results.json
6. 每批完成后输出该批的中间结果供确认

### 最终输出

- **results.json**：全量评分中间文件，逐批追加，包含每份的A/B/C/D/E/总分/定档/备注
- **evaluation_results.csv**：CSV总表（按总分降序排序），包含所有字段
- **评价报告**：全量分析+Legendary详细点评+Rare简明备注

### 评分标尺校准机制

| 锚点 | 说明 |
| --- | --- |
| 已评分最高分（群） | 确保新批次的"顶级"不降级到"优秀" |
| 中位分 | 确保新批次的"普通"不漂移到"优秀" |
| 最低分 | 确保新批次的"差"不升格为"普通" |


### 定档流程

1. 全部评分完成后，按总分降序排列
2. 按比例划档：Legendary ≤10%（前36名内），Rare ~20%（37-107名），Common (108-357名)
3. Legendary线附近的并列做tiebreaker：先比B+E总分，再比多层涌现
4. 定档比例不超过10%（传说可少于10%）
