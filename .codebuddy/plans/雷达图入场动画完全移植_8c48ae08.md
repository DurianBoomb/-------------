## 需求

将 `result.vue` 中的雷达图绘制全面重写为 Figma 设计的 10 层入场动画方案，基于以下三个已确认的决策：

1. **颜色方案**：跟随 Figma 统一橙色系（#F97316 / #FB923C），移除当前 per-dimension `colors` 数组
2. **画布尺寸**：改用 Figma 的 280x280 逻辑尺寸正方形，CSS 层做对应调整
3. **入场节奏**：CSS 容器 scale + Canvas 内部动画并行，Canvas 内部 START_DELAY=450ms，总时长 1900ms

### 核心功能

- 10 个动画图层：网格弹出 → 轴线射出 → 冲击波 → 数据飞射 → 填充/描边 → 白闪高光 → 顶点弹性弹出 → 数字滚动 → 标签淡入
- 自适应 N 维 stagger 时间窗，3~8 维都能合理错峰
- rAF 每帧全量重绘，进入页面时完整重播
- CSS 四阶段入场 + Canvas 内部动画组成完整"揭晓答案"时序

### 视觉效果

橙色系雷达图从中心引爆逐层生长，约 2350ms 完成全部入场，营造仪式感。

## 技术方案

### 技术栈

- **框架**：Vue 2 + uni-app + uniCloud（微信小程序）
- **渲染**：微信小程序 Canvas 2D（`<canvas type="2d">`）
- **动画驱动**：`requestAnimationFrame` 逐帧全量重绘
- **DPR 处理**：运行时获取 `pixelRatio`，`ctx.scale(dpr, dpr)`

### 实现策略

严格按 Figma 文档（docs/figma-prompts/雷达图-入场动画设计.md 第 5-8 节）的精确参数实现，逐字对应：

1. **全局常量写死**：SIZE=280, CENTER=140, RADIUS=90, DURATION=1900, START_DELAY=450
2. **缓动函数照抄**：sub(), easeOutCubic(), easeOutBack(c1=1.70158), easeOutElastic(c4=2PI/3)
3. **时间窗机制**：frac(i,N)→[0,1], win()→[a,b] 归一化进度窗口
4. **rAF 主循环**：tick() + start()，重置时 cancel 旧 raf + 重置 startTs=0
5. **10 层按序绘制**：Layer 1 (最底层) → Layer 10 (最上层)，每帧先 clearRect 全量重绘
6. **状态复位**：每帧结尾 ctx.globalAlpha=1, ctx.setLineDash([])

### 关键决策

- **绘制策略**：每帧全量重绘，不做分层。10 层全是动态的，分层反而复杂
- **性能**：N=5 时单帧约 30-40 次 sin/cos，<2ms，低端机按真实时间推进不受帧率影响
- **颜色**：统一橙色系，移除 colors 数组/hexAlpha/genPalette 等旧代码
- **CSS 协同**：保留 CSS 层容器 scale，Canvas 用 START_DELAY 等容器 scale 快完成后再启动内部动画

### 架构设计

修改仅在 `result.vue` 内完成，不新增文件：

- **CSS 层**：现有的 scoped style + 新增 @keyframes 入场动画 class
- **Template 层**：给 4 个区域元素添加动画 class
- **Script 层**：重写 drawRadar 方法（约 80 行 → 约 350 行），删除旧的颜色辅助方法
