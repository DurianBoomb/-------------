基于已编写好的开发文档 `docs/微信静默注册开发文档.md`，在微信小程序端实现静默注册/登录功能。

**改动范围：** 仅修改 `App.vue` 一个文件，共三处改动：

1. **新增 import**：在 `<script>` 顶部引入 `store` 和 `mutations`
2. **onLaunch 新增调用**：在 `uniIdPageInit()` 之后添加 `#ifdef MP-WEIXIN` 包裹的 `this.silentLogin()`
3. **新增 `silentLogin` 方法**：检查 token 是否存在，不存在则调 `uni.login()` 获取 code，再调 `uni-id-co.loginByWeixin()` 自动注册或登录。成功时更新 store 状态并触发事件，失败时只 console.warn 不弹窗。

后端代码无需改动（已确认 `login-by-weixin.js` 自动注册逻辑正常，`config.json` 中 appsecret 已配置）。

## 技术方案

### 技术栈

- Vue2 + uni-app + uniCloud
- uni-id-pages / uni-id-co（用户认证体系）
- 微信小程序（条件编译 `#ifdef MP-WEIXIN`）

### 实现策略

静默注册 + 无感登录。小程序启动时自动调 `uni.login()` 获取微信临时 code，后端用 code 换 openid，通过 `preUnifiedLogin` 自动注册或登录。用户全程无感知，不弹任何授权框。

### 关键设计

1. **单文件改动**：只改 `App.vue`，后端和配置无需修改。已验证 `login-by-weixin.js` 第 99-109 行自动注册逻辑正常，`uni-config-center/uni-id/config.json` 中 `mp-weixin.oauth.weixin.appsecret` 已配置。
2. **条件编译隔离**：用 `#ifdef MP-WEIXIN` 确保逻辑只在微信小程序端生效。
3. **容错设计**：所有异常只 console.warn，不弹窗不打断用户。静默注册失败后页面仍正常显示，只是后续数据操作受限。
4. **状态同步**：成功后通过 `mutations.setUserInfo()` 更新 store，并触发 `uni-id-pages-login-success` 事件让页面监听。
5. **`customUI: true`**：告诉 uni-id-co 不要弹 loading/toast，保持纯静默。

### 实现注意事项

- `uni.login()` 在微信小程序中不弹授权框
- 修改后需删除 unpackage 缓存再运行（HBuilderX 缓存 bug）
