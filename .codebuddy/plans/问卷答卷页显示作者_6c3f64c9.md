在问卷结果展示页（result.vue）显示问卷作者的名字。目前该页面只展示结果 emoji、结果名称、描述、雷达图等，没有作者信息。

核心改动点：

1. 云函数 `getSurveyDetail` 增加返回 `creatorNickname`
2. `result.vue` 在加载结果时获取作者名字并展示

## 技术方案

### 实现思路

- **云函数端**：在已有 `getSurveyDetail` 方法中，当问卷有 `creatorId` 时，联查 `uni-id-users` 表获取 `nickname`，返回 `creatorNickname`
- **前端**：`result.vue` 的 `onReady` 中，与 `loadVoteInfo` 并行调用 `getSurveyDetail`，拿到作者名后展示在描述卡片底部

### 技术选型

- 沿用现有 Vue2 + uni-app 框架
- 云函数使用已有 `getSurveyDetail` 方法，不新增方法
- 客户端使用现有 `uniCloud.importObject('survey')` 调用模式

### 关键设计决策

- **不在前端直连数据库**：虽然 `answer-quiz.vue` 用了客户端 DB 查询，但 `result.vue` 走云函数更统一，且 `getSurveyDetail` 本身就是为这个场景设计的，复用它减少重复代码
- **不修改数据结构**：`surveys` 表已有 `creatorId` 字段，不新增字段，不存名字只存 ID

### 数据流

```
result.vue onReady
  -> survey.getSurveyDetail({ surveyId })
    -> surveysCol.doc(surveyId).get()  // 拿到 creatorId
    -> uni-id-users.doc(creatorId).field('nickname').get()  // 拿到昵称
    -> return { creatorNickname: 'xxx' }
  -> 展示 "作者：xxx"
```

### 目录结构

```
pages-tools/

uniCloud-alipay/
  cloudfunctions/

```

### 执行细节

- 云函数改动仅在 `getSurveyDetail` 方法内，不影响其他方法
- 用户昵称为空时返回 `''`，前端用 `v-if` 控制展示
- 预置问卷的 `creatorId` 为空，不显示作者行
- 兼容性：老数据没有 `creatorId`，`v-if` 自然不展示，无报错
