## 阶段零：前置检查

调用云函数 `survey.checkDuplicates()` 确认 `surveys` 表中不存在重复的 `tagName` 记录，为阶段三的索引变更（从 `tagName_unique` 单字段唯一索引改为 `tagName_creatorId_unique` 联合唯一索引）做安全验证。

### 检查内容

- 调用已有的 `checkDuplicates()` 方法（`index.obj.js` 第 416 行）
- 验证返回 `data.total === 0`
- 若返回 `total > 0`，列出重复记录详情

### 预期结果

由于当前 `surveys` 表已有 `tagName_unique` 单字段唯一索引保护，理论上不会存在重复记录，`total` 应为 `0`。

## 技术方案

### 调用方式

`checkDuplicates()` 是 `survey` 云对象的公开方法，无权限限制，不需要登录即可调用。在小程序端通过以下方式调用：

```javascript
const survey = uniCloud.importObject('survey')
const res = await survey.checkDuplicates()
// res.errCode === 0 表示成功
// res.data.total === 0 表示无重复
```

### 实现方法（已有，无需改动）

**文件**：`uniCloud-alipay/cloudfunctions/survey/index.obj.js` 第 416-442 行

```javascript
async checkDuplicates() {
    const res = await surveysCol.aggregate()
        .group({
            _id: '$tagName',
            count: { $sum: 1 },
            ids: { $addToSet: '$_id' },
            creatorIds: { $addToSet: '$creatorId' },
            earliestDate: { $min: '$create_date' }
        })
        .match({ count: { $gt: 1 } })
        .sort({ count: -1 })
        .end()
    // 返回 { errCode: 0, data: { total, duplicates[] } }
}
```

### 执行注意事项

- 纯读取操作，不修改任何数据
- 不需要登录态
- 可在小程序端直接调用并打印结果
- 如果有重复（极少见），先用 `deduplicate({ tagName })` 清理
